# 98: 灰度开关与敞口限额

**What to build:** 房主能一键让期货进入「只跑不花钱」的影子模式，也能一键停掉并把托管余额原路退回；任何人在任何情况下都刷不爆这个市场——日额、名义敞口、发包频率三道闸会先拦住他。

**Blocked by:** 97 (真强平与保险基金兜底)

**Status:** ready-for-agent

- [ ] 三档模式：`off`（窗口显示未开放、报文一律不理）/ `shadow`（撮合、结算、强平全跑，但充值提现只记账不碰农场硬币）/ `live`（真钱）。
- [ ] 影子模式对账：跑满一段时间后，能导出一份「记账流水 vs 农场硬币差额」的核对结果，差额必须为 0。
- [ ] 限额：单账户日交易额 5,000 币、同时持仓名义 20,000 币、同源地址 20 包/10 秒；超限时返回具体原因（`daily-cap` / `notional-cap` / `rate-limited`）。
- [ ] 影子模式下日额上限为 0（只允许观察与自成交外的撮合），切到 live 才放开。
- [ ] 回滚：关闭开关 → 强制平掉所有仓位（按最后公允价）→ 托管余额逐笔退回各人农场 → 存档打 `disabled` 标记但保留数据，不删。
- [ ] 提现撞上农场 1,000,000 上限时，剩余部分留在托管账并显示「待提取」，不静默丢钱。
- [ ] 窗口里每个拒绝原因都有中文文案，不是裸错误码。
- [ ] 测试：三种模式的状态机、三个上限各自的边界（差 1 通过、等于拒绝）、回滚后退款金额与账面一致。
