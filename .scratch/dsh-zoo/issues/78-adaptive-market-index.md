# 78：自适应局域网行情指数

**Status:** ready-for-agent
**Depends on:** 39（交易所）、42（局域网指数）、48（市场深度）

## Problem

交易所的局域网指数固定占 15% 权重。只有一家邻居时几乎看不出来，
三家以上也还是 15%，玩家感受不到“同一个市场”。直接改成 75% 又会让
单家邻居主导价格，且一次异常报价就能把价格拽走。

## Solution

- 权重按新鲜邻居数分档：0/1/2/3+ 家 → 0% / 45% / 65% / 75%。
- 乘作物 beta（0.8–1.4），有效权重封顶 85%。
- 指数中位数叠加邻居最近一轮涨跌的中位数作为动量，单轮夹在 ±12%。
- 只影响卖价；买种子固定价；`/state` 的指数形状不变，窗口额外带
  `weight/momentum/stale`。
- 没有新鲜邻居时仍显示「本机行情」。

## Acceptance

- `computeMarketIndex` 对 0/1/2/3 家、未知作物、坏价格、过期样本都有确定结果。
- `market.json` 落盘/重启保留 `momentum`；旧文件按 0 读入。
- 窗口行情行显示 `指数 52% · 2 家 ↑3.0%`，过期画灰。
- 卖价使用自适应权重，买种子价不变。
- `npm run check` 全绿；真实农场窗口 smoke 不回归。

## Out of scope

- 互联网/全球行情、跨局域网联邦。
- 24 小时 sparkline（后续票）。
- 做空、期货、订单簿。
