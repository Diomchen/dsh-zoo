## 设计依据（/ui-ux-pro-max 检索结果）

- 风格命中 `sketch-hand-drawn-mobile`（wobbly 圆角、2–3px 墨线、硬投影、纸感底、轻微旋转），
  与现有手绘 K 线同一条路线；不引入字体文件（系统字体 + tabular-nums）。
- UX 规则：**文字不得在固定高度盒子里被裁**；相邻点击目标 ≥8px；禁用态要降低不透明度并
  给原因；不要只靠颜色传达涨跌（跌用空心蜡烛 + 正负号）；每屏动效 ≤1–2 处；焦点环必须可见；
  实时更新不得抢焦点。
- `--design-system` 首轮返回的是深色企业站模板（不匹配本产品），已按 skill 要求改用显式
  `--domain style/ux` 的命中行，不采用那份配色。

## 要做的

1. **布局**（760×700 固定）：
   - 顶栏 54：`盘口` + 当前作物 / 本周盈亏胶囊 / 可用·锁定 / 倒计时 / ×。
   - 作物条 44：单行横向滚动（左右箭头 + 滚轮 + 键盘），chip 支持任意数量；右侧 4 档周期分段控件。
   - 图 288：占满宽度（沿用票 87 的手绘 SVG）。
   - 下方两列：左 = 持仓（可滚动）+ 最近结算（可滚动）；右 = 下单（**不滚动、不裁切**）+ 周榜。
2. **下单区**：标签在左、控件在右的两列行；保证金 4 档、杠杆 3 档用等宽 grid（`minmax(0,1fr)`），
   任何窗口宽度下都不溢出；主按钮固定在卡片底部；预览句保留一行，其余提示删掉。
3. **文案瘦身**（硬性）：正文/标签 ≥12px，只有图表轴刻度允许 11px；删掉副标题、`关：直接…`、
   长提示与长空态，空态一行（`还没有持仓` / `还没有结算` / `等邻居上线`）；
   提示只保留：预览句、`差 N 硬币`/`去种地`、`15 分钟结算`。
4. **手绘 token**：纸感底、wobbly 圆角、2px 墨线、`2px 2px 0 rgba(47,58,52,.08)` 硬投影、
   局部 −0.4°~0.4° 旋转；跌蜡烛改**空心**（不只靠颜色）；焦点环 2px 虚线墨色 offset 2。
5. **无裁切验收**：10 种作物 + 4 个持仓 + 3 条结算 + 3 行周榜 + 到价面板展开时，
   760×700 下所有控件完整可见（该滚动的列表内部滚动，页面不滚、卡片不裁）。
6. **测试**：`test/trading-view.test.js` 覆盖新文案/作物条/分段控件/空态/空心蜡烛/禁用原因；
   `test/board-window.test.js` 覆盖布局常量与 DOM 结构；保留全部既有用例。
