# 97: 真强平与保险基金兜底

**What to build:** 亏到 1/杠杆 就真的会被平掉——20× 在 5% 逆行上不再是一句空话；平掉后还有缺口时，保险基金先补，基金空了就记账，玩家的余额永远不会变成负数。

**Blocked by:** 96 (到期交割与转现货)

**Status:** ready-for-agent

- [ ] 强平线 = 1/杠杆（1× 没有强平线）；只在保证金被吃穿时触发，不提前、不延后。
- [ ] 判定按根内路径而不是收盘价：用与盘口同款的逐 tick 路径扫描，插针也能扫到；同一根内多个仓位按触发价顺序执行、同价按建仓时间。
- [ ] 强平后 `marginUsed` 清零、`balance` 不为负；成交记录写明「强平」与触发价。
- [ ] 保险基金：费用 10% 持续注入；强平亏空先由基金补，基金不足时记一笔「欠账」累计值，不向玩家追缴。
- [ ] 基金与欠账都能在状态接口和窗口里看到。
- [ ] 测试：构造一笔 20× 多单，用可控路径在 5.1% 逆行处触发，断言强平价、余额不为负、基金减少的数额等于亏空；再构造基金为 0 的场景断言只增加欠账。
- [ ] 盘口逻辑与价格公式不受影响（`trading.js` 一行不改）。
