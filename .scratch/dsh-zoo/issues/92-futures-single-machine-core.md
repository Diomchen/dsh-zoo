# 92: 单机期货核心——托管账户、做市报价、每根结算

**What to build:** 服务起来就能把农场硬币充进交易所、按做市商报价做多或做空一手、每根收盘按公允价结算、随时把余额提回农场。单机（房主就是自己、没有邻居）走完这条路，市场就是完整可用的。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 充值：农场硬币减少、托管账户 `balance` 等额增加；提现原路退回，金额超过 1,000,000 时自动分批并核对农场实收数量（加币会静默截断）。
- [ ] 行情：公允价 = 现货指数 × exp(OU 偏离)，OU 是均值回归噪声（σ 0.4%、半衰期 30 分钟、每 15 秒一步），由散列派生；买一/卖一在公允价两侧各让 0.2%；同一时刻在两台机器上算出同一个数。
- [ ] 吃单：吃卖一开多、吃买一开空；保证金从 `balance` 划到 `marginUsed`；张数 = floor(名义价值 ÷ (成交价 × 100))，至少 1 张；taker 费 0.1% 名义当场扣。
- [ ] 结算：每根结束按收盘公允价结算，盈亏 = 张数 × 100 × (现价 − 入场) × 方向，记入 `balance` 并释放 `marginUsed`；一根只结算一次，进程重启后不重复入账。
- [ ] 费用去向：taker 费的 10% 进保险基金、90% 计入销毁，状态接口能读到两个累计值。
- [ ] 坏存档按空市场运行、只告警一次、不写回；农场与盘口不受影响。
- [ ] 脚本级验收：充值 100 → 开多 → 等一根结算 → 平仓 → 提现，全程 `balance + marginUsed` 守恒，差额恰好等于手续费与盈亏。
- [ ] 单测覆盖：OU 的回归方向与边界、张数取整、费用拆分到分、结算幂等。
