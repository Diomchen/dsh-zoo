# 92: 单机期货核心——托管账户、做市报价、每根盯市结算

**What to build:** 服务起来就能把农场硬币充进交易所、按做市商报价做多或做空一手、每根收盘按公允价盯市、随时把余额提回农场。单机（房主就是自己、没有邻居）走完这条路，市场就是完整可用的。
