# 93: 期货窗——看盘、吃价下单、持仓与成交

**What to build:** 从桌面右键或农场窗打开一扇 760×700 的期货窗，能看见 15 个作物本周合约的买卖报价与偏离、下一手要多少保证金和强平价在哪、自己的持仓和最近成交，并能直接下单和平仓。关窗不影响后台结算。

**Blocked by:** 92 (单机期货核心)

**Status:** ready-for-agent

- [ ] 独立 focusable 窗口，尺寸与位置沿用盘口窗的做法（位置存盘、越界回收）；关窗后市场照常运转。
- [ ] 报价区：每作物一行——合约代号、买一/卖一、价差、公允价相对现货指数的偏离、点差百分比。
- [ ] 本根倒计时：显示距下一次撮合/结算还有多久，到点自动刷新。
- [ ] 下单区：做多/做空、1×/3×/10×/20×、张数与保证金额度；下单前实时显示「保证金 / 名义价值 / 强平价 / 手续费」四个数，任一为空则禁用提交。
- [ ] 持仓区：合约、方向、张数、入场价、保证金、强平价、浮盈亏；浮亏接近强平线时整行变红；可一键平仓。
- [ ] 成交记录最近 20 条：时间、合约、方向、价格、张数、手续费。
- [ ] 顶部展示可用余额、占用保证金、本周盈亏与收益率。
- [ ] 空态（没充钱）、加载态、错误态（服务未就绪 / 合约已到期）都有明确文案。
- [ ] IPC 走白名单，渲染层不 import 规则层；窗口刷新或重开不丢状态、不重复下单。
