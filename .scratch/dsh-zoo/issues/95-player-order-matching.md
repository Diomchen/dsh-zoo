# 95: 玩家挂单撮合——限价单、价格优先、每根成交

**What to build:** 两个人可以直接对着彼此下单：A 挂一张限价单，B 用更好的价格吃它，成交价就是 A 挂的价，钱从 B 的托管账户转到 A 的托管账户，两边各付自己的那份手续费。没成交的单子挂在那里等下一根。

**Blocked by:** 94 (双机开户与净额结算)

**Status:** ready-for-agent

- [ ] 限价单进队列：合约、方向、价格、张数、保证金；下单即冻结对应保证金。
- [ ] 每根（以及每根内的价格触及）按「价格优先、同价时间优先」撮合；成交价 = 挂单价（maker 价），不是对手价。
- [ ] 玩家对玩家成交时，钱在两人的托管账户之间转移：多头付钱拿仓、空头收钱交仓，双方 taker/maker 费用按规则收取。
- [ ] 撤单立刻释放冻结的保证金；已部分成交的只释放剩余部分。
- [ ] 挂单可以跨根存活直到合约到期；到期那次结算前统一撤销（语义在 96 落地，这里先不撤）。
- [ ] 同一个人不能与自己成交（自成交防护），也不能下超过余额能支撑的张数。
- [ ] 撮合顺序可复现：给定同一组订单与同一个价格，任何机器算出同一个成交序列（测试用固定顺序断言）。
- [ ] 双机 e2e：A 挂单、B 吃单，一根后两人余额变化之和只等于手续费的负数。
