# 85: 盘口窗可拖动 + 点窗口外面收起所有窗口

**Blocked by:** 79–83（已合并）

**Status:** done

## 问题

盘口窗 760×700 居中、`movable:false`，挡住桌面也挪不开。另外所有窗口都**故意不按 blur 关**
（当年为了躲 macOS 输入法候选窗抢焦点），于是点外面窗永远收不起来。

## 要做的

- 盘口窗可拖动：`movable:true`，标题栏 `.topbar` 用 `-webkit-app-region: drag`，里面的按钮/页签
  `no-drag`；松手后把位置写进 `userData/board-window.json`，下次开窗恢复并夹进当前工作区
  （离屏/坏文件回落到居中）。
- 点窗口外面（任一插件窗失焦，且焦点没有落到另一扇插件窗）→ 200ms 后**收起所有插件窗**
  （盘口 / 农场 / 带派 / 改名）。延迟是为了躲开「打开另一扇窗」的瞬时失焦。
- 输入法保护：窗口在 `compositionstart`..`compositionend` 之间失焦不收起（候选窗抢焦点会误触）；
  冒烟用的 blur 锁同样跳过。其它情况一律收起。
- 不改 Esc/× 关闭；不改窗口尺寸与点击穿透。
