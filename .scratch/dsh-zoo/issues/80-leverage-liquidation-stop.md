# 80: 杠杆、强平与一键止损

**What to build:** 在 79 的开仓/结算路径上加入 1×/5×/20×、强平和一键止损：玩家能看到强平价和「涨 1% = ±X」；价格撞到强平线（tick、插针、快进、离线补算）自动平，只亏保证金，不欠钱；持仓卡一键设止损（关 / −25% / −50% / −100% 保证金），到线自动平。

**Blocked by:** 79

**Status:** ready-for-agent

**Spec:** [SPEC v10](../SPEC-v10.md)

## 关键决定

- 强平：做多 `mark ≤ entry × (1 − 1/leverage)`，做空 `mark ≥ entry × (1 + 1/leverage)`；1× 无强平（显示「—」）。
- 亏损上限 margin；硬币不变成负数；结算取整。
- 快进/离线按剩余路径检查强平；不能靠「直接按到收盘」躲插针。
- 止损是玩家工具，默认关；到线按当前 mark 平，原因「止损」。
- 没有手续费/资金费/缓冲/追保。

## 验收

- [ ] 5×/20× 开仓；仓位、强平价、「涨 1% = ±X」正确；1× 显示「—」。
- [ ] 强平线 `1/杠杆`；tick/插针/快进/离线补算都能强平；只亏保证金，硬币不为负。
- [ ] 止损一键循环；到线按 mark 平；原因「止损」；默认关不触发。
- [ ] 盈亏/取整/无手续费与 SPEC 一致；纯规则 + e2e；`npm run check`。
