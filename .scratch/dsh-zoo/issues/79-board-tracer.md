# 79: 盘口 tracer：看价 → 开一手 → 收盘结算

**What to build:** 玩家从桌面右键/农场窗打开一扇新的盘口窗，看到当前 15 分钟合约价和倒计时；用农场硬币开一手 1× 多/空（50/100 保证金），硬币当场锁定；收盘或手动平仓时按 `保证金 + 盈亏` 退回硬币，并留下一条历史。只做一个作物、1×；K 线、三作物、杠杆、止损、真邻居都在后面的票。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

**Spec:** [SPEC v10](../SPEC-v10.md)

## 关键决定

- 盘口是独立于现货的 15 分钟合约；做市商永远报价；合约价不写 `market.json`。
- 行情由 `slot + crop + 版本盐` 确定性生成；15 分钟一个 slot、1 分钟一个 tick；价格锚作物底价，夹在 0.55–1.75 倍。
- 钱包是农场硬币：开仓锁 `margin`；盈亏 `margin × leverage × 价格变化`；没有手续费/资金费/缓冲；亏损上限 margin。
- 第一版只做 `tomato`、1×、多/空、50/100；持仓/历史/硬币/窗口要能持久化。
- 盘口窗口约 760×700，focusable；桌面右键 + 农场窗入口；关窗不挡宠物。
- 现货、农场、旧邻居行为不变。

## 验收

- [ ] 桌面入口打开盘口窗；显示当前一根的价格 + 15 分钟倒计时；关窗不挡宠物。
- [ ] 做多/做空 1×、50/100 保证金一键开仓；硬币锁定；持仓卡显示入场/现价/盈亏。
- [ ] 15 分钟收盘（假时钟）或手动平仓结算；硬币退回 `保证金+盈亏`；历史一条；无手续费。
- [ ] `trading.json` 持久化；重启恢复；坏文件按空盘口运行并告警一次。
- [ ] 纯规则 + store + 一条 e2e；`npm run check` 全绿。
