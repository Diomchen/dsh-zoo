# 91: 盘口窗去拥挤（下单改横条）+ 折线图 + 黑白模式

**Status:** ready-for-agent

## 用户反馈（2026-11-17）

1. 「修复完成后，还是要优化盘口布局，现在看起来好拥挤，特别是下单」
2. 「支持切换折线图」
3. 「支持柱子颜色切换（黑白模式），主要是防老板」

## 设计依据（/ui-ux-pro-max）

- `--domain ux`：相邻点击目标 ≥8px；文字不得被固定高度裁切；表单标签可见；提交要有反馈；
  键盘顺序与视觉顺序一致。这些在票 89 已部分落地，这次用「把下单从 300px 窄列里拿出来」根治拥挤。
- `--domain chart`：折线图适合看趋势（时间轴、连续变化）；蜡烛图适合 OHLC。
  两者都不许只靠颜色（实心/空心 + ▲▼ + 正负号）。
- `--domain color`：黑白配色用 `#18181B` 墨色 + `#FAFAFA` 纸底，正文对比 ≥4.5:1。

## 要做的

### A. 布局：下单改成图下横条（760×700 不变）

- 行：顶栏 50 / 作物+周期条 40 / 图 268 / **下单横条 ~104** / 底部区剩余 / 间距 10。
- 下单横条（全宽 ~740）：
  - 第一行：`做多 / 做空` + `50 / 100 / 250 / 全下` + `1× / 5× / 20×` + `开一手`（主按钮 132×36）；
  - 第二行：预览（`涨 1% +0.5 · 跌 1% −0.5 · 强平价 —`，单行）+ `到价` 开关 + 一行短提示；
  - 不滚动、不裁切，控件 ≥30px 高、间距 ≥10px。
- 底部：左列 = 持仓（可滚动）+ 最近结算（可滚动）；右列 = 真人周榜（可滚动）。
- 图表下方与下单横条的关系要一眼看出「看涨/看跌 → 开仓」。

### B. 图表类型：蜡烛 / 折线

- 顶栏右侧加「显示」按钮（小弹层），两组分段控件：`图表：蜡烛 / 折线`、`配色：彩色 / 黑白`；
  弹层外点击/Esc 关闭；键盘可达。
- 折线：收盘价折线 + 12% 面积填充 + 现价圆点；坐标轴/参考线/十字线保持；十字线便签仍显示
  开/高/低/收；空态与加载态同现有逻辑。
- 快捷：`L` 切蜡烛/折线、`M` 切彩色/黑白（输入框聚焦时不触发）；预选状态存
  `localStorage['dsh-zoo-board-prefs']`（失败静默）。

### C. 黑白模式（防老板）

- `body[data-mono='1']` 覆盖 token：emerald/rose/amber → 墨色/石墨灰，soft 背景 → 纸灰；
  卡片、chip、按钮、周榜、盈亏数字全部去饱和。
- 涨跌不只靠颜色：涨=实心墨色、跌=空心墨色；数字带 ▲▼/±；折线=墨色。
- 对比度 ≥4.5:1；焦点环、禁用态、空态在黑白下仍清晰。
