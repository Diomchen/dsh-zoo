# 96: 到期交割与转现货

**What to build:** 合约有寿命：周一早上开新的一周，周五晚上八点整所有仓位按最后四根收盘均价结清，没成交的挂单自动撤掉；玩家也可以在到期前随时把手里的仓位换成真作物。

**Blocked by:** 95 (玩家挂单撮合)

**Status:** ready-for-agent

- [ ] 每周一 00:00（本地时间）为每个作物上新合约，代号 `<crop>-<YYYY>W<WW>`；作物目录增减时自动跟随。
- [ ] 周五 20:00 到期：先撤掉全部未成交挂单并退回保证金，再按交割价现金结清所有仓位，最后把合约标记为已交割。
- [ ] 交割价 = 19:00–20:00 四根 15 分钟收盘价的算术平均；窗口里能看到这四根与被算出的交割价（可复核）。
- [ ] 现金交割：差额进/出 `balance`，`marginUsed` 清零，成交记录写明「交割」。
- [ ] 转现货：玩家主动操作，按当前公允价成交 N 个作物进仓 + 平掉等量合约，两步要么都成要么都不成；作物不够或余额不够时明确拒绝。
- [ ] 到期前后边界：19:59:59 还能下单，20:00:00 之后一律拒绝并提示「合约已到期」。
- [ ] 跨周：周六到周日没有可交易合约，窗口显示「本周合约已交割，下周一 00:00 开新合约」。
- [ ] 测试用假时钟覆盖：周一开盘、周五 19:59、20:00、周六四个时刻。
