# dsh-zoo · IP 候选（SVG 版）

六张候选，三个方向各两张。`ips-as-logo` skill 默认禁止 SVG 兜底；这一组是在**没有可用图像模型**、
且你明确要求"用 SVG 兜底"之后，手工绘制的矢量版本，不冒充模型出图。

## 一眼总览

| 编号 | 方向 | IP 两色 | 背景 | 说明 |
| --- | --- | --- | --- | --- |
| A1 | 圆耳朵柯基（近景，头爪同框） | 焦糖棕 `#C68B54` + 奶茶白 `#F6EDE0` | 鼠尾草绿 `#8FA58C` | 标准裁切，带嘴 |
| A2 | 圆耳朵柯基（更近的裁切） | 同上 | 同上 | 脸更大、没有嘴，更"符号" |
| B1 | 蹲坐的橘猫（尾巴绕到右侧） | 橘 `#E98A45` + 奶油 `#F7E9D2` | 灰蓝 `#7C8FA6` | 尾巴 + 胸前奶油色 |
| B2 | 蹲坐的橘猫（脸部近景） | 同上 | 同上 | 无尾巴、无嘴，最简化 |
| C1 | 宽围巾小水獭 | 深可可 `#6B4A3A` + 芥末黄 `#D9A43F` | 雾霾青 `#6E9491` | 围巾横过胸口，垂下一段 |
| C2 | 宽围巾小水獭（近景） | 同上 | 同上 | 围巾更低、脸更大 |

全部：`1536 × 1536`、1:1、纯色背景、左下角探入（画布左侧/底部裁切）、
严格三个语义色、无文字、无描边、无阴影、无边框。

## 文件

```
A1.svg … C2.svg      矢量源文件（可直接改数、改色）
A1.png … C2.png      1536 × 1536 位图预览
contact-sheet.svg    六张拼版（3 × 2）
contact-sheet.png    拼版预览
build.py             生成脚本，所有几何与配色都在里面
```

## 重新生成

```sh
python3 build.py
# 位图预览（macOS 自带 Chrome）
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
for f in A1 A2 B1 B2 C1 C2; do
  "$CHROME" --headless --hide-scrollbars --force-device-scale-factor=1 \
    --window-size=1536,1536 --screenshot="$PWD/$f.png" "file://$PWD/$f.svg"
done
```

## 已知取舍

- 帽子/围巾/耳朵这些识别特征都做成了圆钝端点，没有尖角；缩放到了 `32 × 32` 仍能认出轮廓。
- 眼睛用两个 IP 色里的浅色，所以是"亮点眼"而不是深色瞳孔（两色限制下没法再加深色）。
- A 方向在纯几何下更像"狐狸/柯基幼犬"，不是严格柯基；C 方向靠围巾和大头区分水獭。
- 没有做透明背景：skill 要求背景是实色满版；需要透明版可以再单独出一套。
