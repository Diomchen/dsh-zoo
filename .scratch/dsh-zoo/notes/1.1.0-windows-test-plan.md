- [ ] 新文件出现：`farm.json`、`market.json`、`contracts.json`（首次种/收或等一拍 tick 后；

- [ ] 桌面**没有** 4 格地块条；农场只在右键「农场」小窗里（见 §2）

安装记录（按你以前的方式）：

```powershell
# 1) 停止 DSH，备份数据
Copy-Item "$env:USERPROFILE\.dsh\dsh-zoo" "$env:USERPROFILE\.dsh\dsh-zoo.bak-20261109" -Recurse

# 2) 把 tgz 放到 Windows 某处，例如 C:\temp\dsh-zoo-1.1.0.tgz
cd "$env:USERPROFILE\.dsh\profiles\desktop"
pnpm add "C:\temp\dsh-zoo-1.1.0.tgz"

# 3) 确认 profile 的 dsh.profile.bundles 里有 "dsh-zoo"
# 4) 重启 DSH
```

确认：

```powershell
(Get-Content "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-zoo\package.json" |
  ConvertFrom-Json).version

$port = <DSH端口>
curl.exe -s "http://127.0.0.1:$port/dsh-zoo/state" |
  ConvertFrom-Json | Select-Object -ExpandProperty farm

curl.exe -s "http://127.0.0.1:$port/dsh-zoo/desktop"
```

`/dsh-zoo/desktop` 重点看 `status.helperPath`、`status.stderr`、`helperStatus.ready`、
`helperStatus.restarts`、`helperStatus.lastError`。

> 1.0.3 升级到 1.1.0 不需要迁移目录；农场三个 JSON 是新增的。若你之前手改过
> `farm.json`，先备份再测。

## 2. 农场小窗 UI 改版（必测，单机）

参考截图：`.scratch/dsh-zoo/notes/47-farm-window-composited.png`、
`47-farm-plant-modal-composited.png`。

### 2.1 打开/关闭

- [ ] 右键自己的宠物 → 菜单里有「农场」；点一下打开小窗
- [ ] 再点一次「农场」→ 小窗关闭（菜单是开/关切换）
- [ ] 小窗右上角 × 能关；Esc 能关
- [ ] 点桌面其它地方，小窗**不**自动关（IME 安全行为，和改名/带派一致）
- [ ] 关掉再开，窗口仍贴着宠物/主屏，内容是最新状态
- [ ] 桌面没有地块条；宠物旁边没有 4 格地/农场按钮

### 2.2 外观/布局

- [ ] 奶白/奶油底、祖母绿/琥珀；圆角卡片、软阴影
- [ ] 顶部：我的农场、`X/4 已种植`、🪙 硬币、💧 露水、×
- [ ] 页签：农场 / 交易所 / 雇工 / 记录；四个都能切
- [ ] 农场页：4 张地块卡（2 列）；没有第 5–20 块的假地
- [ ] 底部常驻：种子背包、收获仓库；三种作物的数量
- [ ] 空/生长/成熟三种卡片样式不同；成熟有轻微弹跳/高亮
- [ ] 420×560 窗口内不裁切、不重叠；滚动条只在需要时出现

### 2.3 播种弹窗

- [ ] 点空地/「+ 种植」→ 底部弹窗打开，标题是「播种 · 地块 N」
- [ ] 三种种子都有：库存、生长时长、产量；库存 0 的行禁用/灰
- [ ] 点有库存的种子 → 种下，弹窗关闭，卡片变「生长中」，种子 -1
- [ ] 「去交易所买种」→ 切到交易所页
- [ ] 点弹窗遮罩/× 能关；不会误种
- [ ] **没有**「随机买种」这种新机制（参考图里有，我们没做）

### 2.4 地块操作

- [ ] 生长中：倒计时在走；进度条随时间前进；浇水/施肥按钮可用
- [ ] 浇水：露水 -1，进度 +10%，同一株只能浇一次
- [ ] 施肥：露水 -5，收获 +1，同一株只能施一次
- [ ] 成熟：收获按钮；收获后作物进仓库、地块回空地、可再种
- [ ] 一键播种：第一个空地 + 第一个有库存的种子；成功后卡片更新
- [ ] 一键收割：所有成熟地块依次收获；有多个成熟时逐条 toast，不并发乱序
- [ ] 忙碌时按钮禁用/不重复提交；失败有明确提示
- [ ] 4 块地都能种/收；没有「第 5 块能点」的假交互

## 3. 农场单机循环（必测）

- [ ] 首次启动：30 硬币、2 颗小番茄种子、4 块空地、0 露水
- [ ] 种番茄 → 30 分钟成熟（真实时间）；收获得 3 个（施肥则 4）
- [ ] 交易所卖番茄：硬币增加；再卖一次价格下降；买种子价格固定
- [ ] 买种 → 种 → 收 → 卖 的硬币不为负；库存数量对得上
- [ ] 关掉 DSH 等 5 分钟再开：生长继续（离线补算，最多 12h）
- [ ] 露水：待机 10 分钟 +1；一天最多 48（`dewEarned` 到 48 后不再涨）
- [ ] `farm.json` / `market.json` 重启后保留；日志最多 50 条
- [ ] 手写坏 `farm.json`（停止 DSH）：启动后回初始农场、只警告一次，
      `identity.json` / `peers.json` / `visits.json` 不受影响
- [ ] 硬币/种子/作物到上限时不崩（正常玩不太会到，可跳过）

## 4. 两台机器（有条件必测）

前提：同一网段、IPv4、互相放行、两边 1.1.0；UDP 45871、TCP 45873 可达；
Windows 防火墙放行**专用网络**。只有一台机器时，本节全部标 `blocked`。

### 4.1 串门 + 偷/帮

- [ ] A 去 B 家串门；B 桌面出现 A 的宠物
- [ ] A 打开 B 的农场：标题是「「B」的农场」；访客 banner 显示守卫/次数
- [ ] 偷成熟作物：A 仓库 +1；B 的卡片显示被偷；B 的日志有「A 偷了…」
- [ ] 偷菜次数：3/访客/农场、5/农场、10/访客；**被抓也计数**，不能重试到成功
- [ ] 守卫：B 宠物在家 30%；B 有雇工 50%；两者 80%；B 宠物出门/打工时 0%
- [ ] 被抓：A 这次白跑；B 的 toast 每访客每天最多一次；日志有记录
- [ ] 帮忙：A 花 1 露水，B 的地 +10%，A 得 1 硬币；次数 3/访客/农场、5/访客
- [ ] A 的驮包显示偷来的作物；串门结束后消失/入账
- [ ] 串门结束/召回/失联后，访客农场页 404，窗口显示「已结束」

### 4.2 交易所行情

- [ ] 两台都在线 30 秒后，交易所页出现「局域网指数」和样本数
- [ ] 一边卖多了，本机价下降；另一边指数跟着变（最终一致，不要求秒同步）
- [ ] 没有邻居/样本过期时显示「本机行情」，不崩
- [ ] 改一边的挂牌，另一边的雇工页在 30 秒内看到 available/reason 变化

### 4.3 雇佣

- [ ] B 在「雇工」页打开挂牌，写时薪/时段，保存
- [ ] A 的雇工页看到 B 的宠物，显示可雇/工资/守卫 0.5
- [ ] A 雇佣：硬币扣 `工资 + ceil(5%)`；B 收到合同；B 的宠物以「打工」角标出现在 A 桌面
- [ ] 雇工期间 B 自家农场守卫 0%；B 的宠物不能再去串门/被雇
- [ ] B 召回 / A 提前结束：按实际时长结算；A 拿回剩余；B 得到 `earned`；手续费不退
- [ ] 重启/断网后合同能结束或补结算；`contracts.json` 不双花
- [ ] 挂牌可用性：B 的宠物在家=可雇；去串门=在串门；在打工=在打工；关挂牌=没挂牌
- [ ] 不能雇自己；一只宠物同时只有一份合同；一个农场最多一个雇工

### 4.4 旧版本邻居（可选）

- [ ] 一台 1.0.3 + 一台 1.1.0：串门/礼物照常；1.1.0 看不到旧端的农场；旧端不崩
- [ ] 旧端不会因为新报文类型/新字段报错（旧端应静默丢）

## 7. 已知限制 / 不是 bug

1. **只有 4 块地**。20 块是未来扩建，UI 已按 `farm.plots.length` 自适应；现在没有第 5–20
   块可种地，也没有假锁定位。
2. **没有等级系统**，所以没有参考图的 LV.x；不要按假等级判 bug。
3. **没有桌面地块条**（票 46 起）；农场只在右键小窗。看到地块条说明装的是旧包。
4. **小窗不按失焦关闭**（IME 安全）；用 ×/Esc/再点「农场」关。
5. 一键播种/收割在 owner 的四个页签都显示（参考图式固定外壳的设计选择）；不是功能错误。
6. 没有中心服务器：行情最终一致、对方离线就不能偷/帮/雇；这是设计。
7. 全量 `smoke:desktop` 在基线就有改名窗焦点失败；农场段/菜单段单独跑是绿的。
   这个失败不是 1.1.0 引入的；如果 Windows 上也复现，记录即可，不算阻塞。
8. 两台机器手工验收在 macOS 开发机上没做（只有一台机器；fake peer 没有农场状态机），
   所以 §4 需要你这边补。
9. 测试脚本的 `--test-concurrency=4` 只是测试稳定性，不影响运行时。
