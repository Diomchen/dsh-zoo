## 0. 这一版改了什么（一句话）

**农场变成公开的**：在家就能看邻居的地（`/dsh-zoo-farm/open/…`），也能派宠物去偷——
两件事都**不需要先放行**；放行只保留"来我家串门"这层含义（ADR-0018 / SPEC v7）。

1.2 之前偷菜要走四步（放行 → 出门 → 到了 → 在窗里找地）。1.3 是两步（右键那一户 → 派它去偷）。

## 2. 看田（look）——本版核心，必测

**入口**：右键邻居小街上的那一户房子（左键仍然是「去串门」）。

- [ ] 弹出一扇只读窗，标题是「「某某」的农场」
- [ ] **没有页签**（农场/交易所/雇工/记录整排都不见了）
- [ ] 副标题一行：「「某某」的农场 · 守卫 30% · 这趟最多 3 块」
- [ ] 地块卡片没有「种/收/浇/施肥」任何按钮；熟的地写「熟了，这一趟可以偷」，生长中的写「还要 x 分」
- [ ] 已经偷过的地写「这一轮你已经偷过了」
- [ ] 底部一条绿色按钮「派它去偷（这趟最多 N 块）」
- [ ] 关窗（× / Esc）之后桌面正常
- [ ] **没有放行也能看**：找一个"对方没放行我"或"我没放行对方"的邻居，右键照样能看

## 3. 派它去偷（raid）——本版核心，必测

在看田窗里点「派它去偷」。

- [ ] 点击后：A 的桌面宠物消失（出门了），A 的农场守卫变 **0%**
- [ ] 8 秒左右后它自己回来；回来时 A 的 `farm.crops` 多了偷到的作物（每块熟地 1 个）
- [ ] A 的记录里多一条：`direction: "out"`、`kind: "raid"`、时长约 8000ms
- [ ] **被偷的那台**：桌面上出现带「偷菜」角标的宠物；它的农场日志有「某某 偷了 小番茄」；
      农场小窗的记录页有 `kind: "raid"` 的入站条目
- [ ] 守卫概率是真的：多偷几次，大约 30%（主人在家）会被抓；被抓时**这一块白跑**，
      但这一趟照样 8 秒后回家，不会卡住
- [ ] 偷客最多在对方桌面待 8 秒左右（不是 30 分钟，也不是 60 秒）
- [ ] 一趟的额度 = 旧的 `perVisit`（4 块地 3 个 / 50 块地 7 个）；额度用完按钮变灰

> 老版本对照：如果对方是 1.2，点「派它去偷」应当**立刻**提示「对方的版本太老，还不支持远程
> 看田和派它去偷」，不会真派出去。

## 6. 单机自检（不阻塞，但能省你很多事）

> 已在 Windows 上验过（见开头那一块）。**你在沙箱化的会话里跑冒烟时要加
> `$env:DSH_ZOO_SMOKE_NO_SANDBOX="1"`**：不加的话 helper 会以 `0x80000003`
> （`STATUS_BREAKPOINT`）退出，报「等待超时：ready」——那是 Chromium 沙箱起不来，
> 不是插件坏了。这个开关在 `scripts/desktop-smoke.mjs` 里本来就有。

```powershell
node "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-zoo\scripts\two-pets.mjs" --lucky
```

- [ ] `look` 打印「地块数 / 熟了几块 / 守卫 % / 这趟还剩几次」
- [ ] `raid` 之后：A 的作物多了、B 的日志有 steal、B 的 `visitors` 里 `kind` 是 `raid`
- [ ] `admit` / `visit` / `hire` 的老流程仍然能走

## 8. 已知限制 / 不是 bug

1. **没有"谢绝偷菜"开关**，也没有保护期——这是 ADR-0018 的决定，不是漏做。
2. **老版本邻居不能看/不能被偷**：`caps` 里没有 `raid`/`look` 就是"只会串门"。
3. 偷客**没有专属动画**，用的是它自己的素材 + 「偷菜」角标。
4. 一趟最多 8 秒（配置项 `raidVisibleMs`，默认 8000）；这不是卡顿。
5. 一个人在别人家串门期间，仍然可以派它去偷吗——**不行**：一次只能出一种门（老规则）。
6. `caps` 目前只用在"能不能看/能不能偷"；界面上没有预禁用（点了才告诉你太老）。
