## Problem Statement

交易所现在是「自己的商店 + 一条 15% 的指数」：买卖的另一方永远是本机做市商，
邻居只贡献一个中位数。上一版「跑一趟」把乐趣押在邻居买货、价差合理上；没人交易、
价格不对，交易所就空了——乐趣依赖别人。

玩家要的是：**打开就能做一单，不用等别人；15 分钟一根、随机但有趋势；能做多/做空；
重交易、轻过程；真邻居；不搞风险控制（输了就老老实实种地）；结算简单；
限价/止损可选。**

## Solution

加一层独立于现货的 **15 分钟合约盘口**：

- 做市商永远报价；行情由确定性种子生成，同一 `slot + crop + 版本盐` 在所有机器上
  是同一张图；LAN 只做同一张图和真人周榜，不做对手盘。
- 做多 / 做空；保证金 × 杠杆（1× / 5× / 20×）；用**农场硬币**下注；没有手续费、
  没有资金费、没有单次/总仓位上限、没有保险、没有重置。
- 结算只有一条公式：`盈亏 = 保证金 × 杠杆 × 价格变化`；强平线就是 `1/杠杆`；
  15 分钟收盘自动结算，随时可手动平仓；亏损上限是保证金，不会欠钱。
- 持仓卡上一键止损（关 / −25% / −50% / −100% 保证金）；到价开仓放 v1.5；
  不做订单簿、不做部分成交。
- 周榜是「本周交易盈亏（金币）」，邻居只上报自己的盈亏和持仓；没有 NPC。
  硬币到 0 就不能下单，只能去种地；农场自己的露水/种子/节日兜底不动。

## User Stories

1. 作为玩家，我想从桌面右键或农场窗一键打开「盘口」，这样不用出门、不用串门就能交易。
2. 作为玩家，我想看到 15 分钟一根的 K 线和最近 24 根，这样我能读出趋势。
3. 作为玩家，我想看到当前这根的价格、风向和 55–68% 的置信度，这样我知道风向不是保证。
4. 作为玩家，我想在三个作物之间切换，这样我能挑趋势最明显的那个。
5. 作为玩家，我想选做多或做空，这样涨跌都有得做。
6. 作为玩家，我想用 50 / 100 / 250 / 全下的保证金，这样不用输入数字。
7. 作为玩家，我想选 1× / 5× / 20× 杠杆，并在下单前看到强平价，这样我知道自己在赌多大。
8. 作为玩家，我想在按钮旁看到「涨 1% = +5 币；跌 1% = −5；强平 −100」，这样不用心算。
9. 作为玩家，我想按一下就把仓位开出来，没有确认弹窗，这样操作是轻的。
10. 作为玩家，我想在持仓卡上看到入场、现价、盈亏、强平价，这样我知道现在什么情况。
11. 作为玩家，我想随时手动平仓，这样我不用等到收盘。
12. 作为玩家，我想在 15 分钟收盘时自动结算，这样我不用一直盯。
13. 作为玩家，我想在 20× 插针时被强平、只亏保证金、不欠钱，这样规则是清楚的。
14. 作为玩家，我想在硬币到 0 时看到「去种地」，而不是被系统塞一笔救济，这样输赢是真的。
15. 作为玩家，我想在硬币够的时候开任意多个仓位，不被「最多 5 个」限制，这样重交易是真的。
16. 作为玩家，我想在持仓卡上一键设止损（关 / −25% / −50% / −100% 保证金），这样我不用盯盘。
17. 作为玩家，我想在 v1.5 里挂一个「到价开仓」，到价成交、收盘没成交就撤，这样我能等回调。
18. 作为玩家，我想看到本周交易盈亏的真人榜，这样我能和邻居比。
19. 作为玩家，我想看到邻居的盈亏、当前持仓和「LAN 情绪」，这样我知道谁在逆势。
20. 作为邻居，我想只暴露我的交易盈亏和持仓，不暴露我的硬币余额，这样我的家底不外泄。
21. 作为玩家，我想在没有邻居上线时看到「等邻居」，行情照走，这样单人也能玩。
22. 作为玩家，我想关掉 DSH 再回来时，持仓已经按错过的收盘价结算好，这样不会丢账。
23. 作为玩家，我想旧版本邻居不影响我，新报文他们静默忽略，这样升级不是所有人一起。
24. 作为玩家，我想盘口和现货交易所互不影响，这样种田、买种、卖作物照旧。
25. 作为玩家，我想在盘口窗口里看到成交历史和结算原因（收盘/手动/强平/止损），这样我知道钱怎么没的。
26. 作为玩家，我想关掉盘口窗口后它不会把宠物挡住，这样桌面还是桌面。
27. 作为玩家，我想在盘口窗口里用键盘 Tab 走完下单/平仓，这样我不需要鼠标也能操作。
28. 作为玩家，我想在窗口里看到「本周」分数每周一清零、硬币不清零，这样我知道榜和钱是两本账。
29. 作为玩家，我想在农民币输光后还能靠露水/种子/节日慢慢回来，这样农场是真正的退路。
30. 作为玩家，我想看到一个明确写着「没有手续费、没有资金费、没有风险控制」的说明，
    这样我不会以为系统在暗中保护我。

## Implementation Decisions

### 词汇

- **盘口**：15 分钟合约市场；只读行情 + 本地持仓，不是订单簿。
- **合约**：以作物为标的、15 分钟一根、现金结算的仓位；不交割作物。
- **一根**：15 分钟 K 线；**一个 tick**：1 分钟。
- **保证金**：开仓时从农场硬币里锁住的本金；**杠杆**：1×/5×/20×。
- **强平**：保证金亏完时自动平仓；**止损**：玩家自己设的提前平仓线。
- **到价开仓**：v1.5 的本地限价单，到价成交、收盘未成交即撤。
- **本周交易盈亏**：周一 00:00 清零的分数；硬币不跟着清零。
- **风向**：慢趋势方向 + 55–68% 置信度；**底价锚**：K 线围绕作物底价，夹在 0.55–1.75 倍。

### 行情

- 15 分钟一个 slot，本地 :00/:15/:30/:45 对齐；每个 slot 有 15 个 1 分钟 tick。
- 价格由 `slot + crop + 版本盐` 的确定性噪声生成；同一套代码、同一时钟的两台机器
  得到同一张图。没有服务器、没有共识；邻居的时钟偏几分钟只会让图偏一根，
  不影响各自的本周盈亏（盈亏是本地的）。
- 慢趋势约 4–6 根一段，快噪声每根一次；价格锚定作物底价，夹在 `[0.55, 1.75] × base`；
  具体幅度由平衡票调，原型里的 exp 曲线只作手感。
- 风向 = 慢趋势方向，置信度 55–68%；快噪声会把弱信号打反，UI 必须写「不是保证」。
- 图表显示最近 24 根 + 当前形成中的一根；当前一根按 1 分钟 tick 揭示开/高/低/现价；
  收盘价就是结算价。
- 盘口合约价与现货 `market.json` 的 bid/price 是两张图；互不写入。

### 交易与结算

- 仓位：`{ crop, side, margin, leverage, entry, liq, stopLoss?, openedAt }`；
  没有「仓位数量」这个会漂移的字段，盈亏直接由保证金 × 杠杆算。
- 做多：`盈亏 = margin × leverage × (mark / entry − 1)`；
  做空：`盈亏 = margin × leverage × (1 − mark / entry)`。
- 强平：做多 `mark ≤ entry × (1 − 1/leverage)`；做空 `mark ≥ entry × (1 + 1/leverage)`；
  1× 没有强平（显示「—」）；亏损上限是 margin，硬币不会变成负数。
- **没有手续费、资金费、点差、0.4% 缓冲、追保**。收盘结算时把 `margin + 盈亏` 退回硬币；
  盈亏按整数硬币结算（展示可保留 1 位小数，入账四舍五入）。
- 15 分钟收盘自动结算所有仓位；玩家可随时手动平仓；强平/止损立即平。
- 快进、离线补结算、跨 tick 跳过时，要按剩余路径检查强平/止损，不能靠「直接按到收盘」
  躲过插针。
- 下单区必须显示一行人话预览：`5× · 100 保证金：涨 1% = +5；跌 1% = −5；强平 −100`。
- 止损：持仓卡上一键循环 `关 / −25% / −50% / −100% 保证金`；到线按当前 mark 平，
  原因写「止损」；默认关，不设也能玩。这是玩家工具，不是系统强加的风控。
- 到价开仓（v1.5）：本地限价单，目标价 + 方向/保证金/杠杆；tick 越过目标价即成交，
  成交价用目标价；15 分钟收盘未成交即撤；可手动撤；不做部分成交。
- 不设「最多几个仓位」；硬币是唯一约束；持仓列表可滚动。
- 仓位卡显示：方向/杠杆、作物、盈亏、保证金、入场、现价、强平、止损、平仓按钮。

### 硬币与账本

- 钱包就是 `farm.json` 的 coins；开仓锁 margin，平仓/结算退回 `margin + 盈亏`。
- 盘口窗口顶部显示「硬币（含锁定 + 未实现）」和「可用」；可用不够时下单按钮禁用并写明原因。
- 硬币到 0 时按钮写「去种地」；不提供救济、不提供重置、不提供保险。
- 硬币上限沿用农场的 1,000,000；盈亏入账要夹取并取整。
- 新增 `trading.json`：`{ version, week: { start, pnl, base }, positions[], orders[],
  history[] }`；只由本机 host 写，写入串行 + tmp/rename，读回按现有 store 的口径逐项修补；
  坏文件按空盘口运行并告警一次。
- 本周交易盈亏：`week.pnl` 存已实现，未实现按当前 mark 现算；周一本地 00:00 清零
  `week.pnl`/`week.base` 并重设 `week.start`；硬币不动。
- 开仓/平仓/结算的硬币变更与持仓写入由 host 串行处理；跨 tick/离线的结算要幂等，
  不能重复扣或重复退。
- 离线：启动时从 `trading.json` 的 openedAt/最后一个已结算 tick 补算；按确定性收盘价
  与路径处理强平/止损/到价；补完写回一次；窗口显示补结算的历史。

### 真人榜与协议

- 没有 NPC。榜上只有本机 + 收到 `trading-digest` 的邻居。
- 新 UDP 报文 `trading-digest`（每 30 秒/peer，最多）：`{ v: 1, type, deviceId, at,
  weekPnl, weekPnlPct?, positions: [{ crop, side, leverage }] }`；只发已放行邻居；
  不包含硬币余额、保证金、入场价、历史。
- 接收端四道门：已放行邻居；`at` 与本机 ≤2 分钟；同一 peer 30 秒最多 1 条；字段/数组
  长度/数值范围白名单（positions ≤ 8）。坏字段整包丢；旧版本邻居静默忽略。
- 榜按 `weekPnl` 降序；旁边的收益率用 peer 自报的 `weekPnlPct` 或本机的
  `weekPnl / weekBase`；收益率只展示，不改排序。
- 「LAN 情绪」= 本机 + 邻居当前 positions 的多空计数；没有仓位写「观望」。
- 邻居的 `weekPnl` 是自报的；不做强防作弊（和 ADR-0016 一致）。
- 旧邻居不认新报文：盘口照常、现货/农场照常；榜里不出现他们。

### 窗口与交互

- 盘口是一扇新的 focusable 窗口（约 760×700），不塞进 520×700 的农场窗。
  入口：桌面右键「盘口」+ 农场窗里的「盘口」按钮。
- 布局：上方 K 线（含当前价格、风向、15 分钟倒计时）；右侧下单区（方向、保证金、
  杠杆、盈亏预览、按钮）；下方持仓卡 + 最近结算；右侧/下方真人周榜 + LAN 情绪。
- 一个按钮开仓、一个按钮平仓；没有确认弹窗、没有订单簿、没有表单（止损/到价除外）。
- 每 1 分钟随 tick 刷新一次；15 分钟边界结算；窗口可关，host 继续结算。
- 硬币不够、没有邻居、旧邻居、窗口关闭、0 仓位都要有明确空态/原因。
- 单测/渲染测试覆盖 view 纯函数；窗口本身沿用农场窗口的 preload/IPC 模式。

### 降级与失败

- 现货交易所、农场、偷菜、雇工、季节完全不动；盘口只是新窗口 + 新 store + 新报文。
- 坏 `trading.json`：按空盘口运行；硬币不动（锁定中的保证金会丢，按一笔坏账处理；
  告警一次）。
- 时钟偏差：盘口用本机 slot；邻居的图可能偏一根；本周盈亏是本地的，不依赖共识。
- 硬币 0：不能下单；农场露水/种子/节日照常。
- 不做强防作弊：邻居能改自己的 `trading.json` / `trading-digest`；榜是社交信任。

### 阶段

- **v1**：行情、做多/做空、杠杆、农场硬币、自动/手动/强平、止损、真人周榜、盘口窗口。
- **v1.5**：到价开仓（本地限价）、收益率列的可选展示、平衡数值。
- 原型里的 60× 快进只用于演示，正式版按真实 15 分钟。

## Testing Decisions

- **好测试**：只测外部行为——同一 seed 同一根的价格、给定 mark 的盈亏/强平、硬币的
  锁定/退回、收盘结算后的硬币、`trading-digest` 的接受/丢弃、榜的排序、view 输出的数字；
  不测私有函数、不测内部循环顺序。用假时钟、确定性 seed，不用 sleep、不联网。
- **缝（待确认）**：
  1. `trading-rules` 纯规则：行情/种子/盈亏/强平/止损/到价/本周盈亏——最高缝，优先。
  2. `trading` store + 农场硬币：临时目录 + 假时钟，测锁币、结算、离线补算、坏文件。
  3. `trading-digest` 协议：纯 parse/merge，测白名单、旧邻居、新鲜度、榜合并。
  4. 盘口 view：纯函数输出图表/持仓卡/榜/空态文案；沿用 `farm-view` 的测法。
  5. 一条 host e2e：开窗口 → 开仓 → 收盘结算/平仓 → 硬币与榜；沿用 `farm-e2e` 的假时钟。
  如果你觉得缝多了，优先保留 1 + 5；2/3/4 可以由 e2e 覆盖一部分。
- **先例**：`test/farm-market.test.js`、`test/market.test.js`、`test/farm-trade-view.test.js`、
  `test/protocol-farm.test.js`、`test/farm-window.test.js`、`test/farm-e2e.test.js`、
  `test/desktop-menu.test.js`。
- **分组**：纯规则/协议/ view 进无网络组（ticket 60 的口径）；e2e 用本地 HTTP/假时钟；
  不新增真实网络测试。

## Out of Scope

- 现货交易所的买种/卖作物规则、农场/地块/作物/合同/季节/来客/偷菜/雇工。
- NPC、赛季筹码、人人 1,000、每周重置硬币、保险、单笔/总仓位上限、追保。
- 手续费、资金费、点差、订单簿、部分成交、撮合、挂单跨收盘、止盈（v1 不做）。
- 1×/5×/20× 之外的杠杆、组合/指数合约、做市商库存风险。
- 强防作弊/签名/共识；邻居的 `trading-digest` 按自报处理。
- 移动端、Web 版、跨设备同步、农场硬币的转账/赠送。
- 旧邻居的升级/兼容改造（旧版本静默忽略新报文即可）。
