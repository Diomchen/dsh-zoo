# SPEC v2 · 桌宠

> 取代 v1 的「客厅」。v1 的 GUI 浮层整块删掉（代码留在 `v0.1.0` 标签里）。
> 协议、发现、信任、串门状态机、记录全部保留。

## Problem Statement

v1 把宠物关在 DSH 窗口的右下角：一小块浮层，一排灯，一张卡片。用户的原话是"为什么限制在这个框内"——因为宠物本来就该在桌面上活着，而不是在应用里当一个挂件。同时「串门」被做成了必须手动触发的动作，而它应该是宠物自己的事：它想出门就出门，别人的宠物想来就来。

## Solution

一只活在桌面上的宠物。它自由走动、被拖、被扔、撞边；它自己决定时不时去某位邻居家待一会儿，去了就出现在对方桌面上；别人家的宠物也会这样出现在你的桌面上，待到你点「送客」为止。

没有客厅，没有第二块屏幕，一个窗口：整个桌面。

## 留下来的与删掉的

**留**：UDP 发现、首次见面放行、`visit-request/ack/deny/recall`、心跳、`peers.json`/`identity.json`/`visits.json`、单端口、4 KiB/白名单/限速/无坐标的协议约束。

**删**：`shell.overlay` 那一整块——邻居灯、访客渲染、串门卡片、客厅里的放行卡、拖到灯上出门、客厅开关。

## 实现决定

**进程模型**：宿主是 `ELECTRON_RUN_AS_NODE=1` 的纯 Node，拿不到 `BrowserWindow`。所以另起一个 Electron helper 子进程（复用 `~/.dsh/electron/Electron.app`，43.3.0，已在机器上），它开**一个**全屏透明、无边框、置顶、不进任务栏的窗口，里面一次画完所有宠物。

**为什么不学 dsh-pet 一宠一窗**：一宠一窗要把"逐帧上报包围盒 + setContentBounds"复制 N 份，而它自己的源码里为多屏 DPI 坐标跳变写了一百多行注释。我们一个窗口画所有宠物，物理和渲染都在一个 React 树里，和 v1 的 client 是同一套代码。

**点击穿透**：窗口默认 `setIgnoreMouseEvents(true, { forward: true })`，渲染端拿到被转发的 `mousemove`，光标进入某只宠物的命中矩形时告诉主进程临时 `setIgnoreMouseEvents(false)`，离开就恢复。只有宠物身体和卡片能接指针，其余一切穿透到桌面。

**数据通道**：helper 与宿主之间走 **stdio 的 JSON 行**，不开端口、不碰 HTTP。DSH Desktop 会拦插件子进程的裸 HTTP 请求（dsh-pet 踩过），stdio 绕开这个问题，也不新增信任面。

**物理**：每只宠物有本地坐标与速度，重力、地面反弹、边缘夹取、被拖时的弹簧跟随、松手投掷。**坐标永不过网**（ADR-0003 不变），访客的运动由本机模拟。

**串门是自发的**（Q2=b）：
- 出门条件四条同时满足：本机最近 10 分钟有活动；距上次出门 ≥ 15 分钟；随机挑中的邻居在线且放行了我；总开关打开（**默认关**）。
- 手动按钮「串门」随时可用：随机挑一个已放行的在线邻居，一家都没有就置灰并提示"还没有人放行你"。
- 串门中我的宠物从桌面消失（"出门了"），对方桌面出现它；「召回」立刻回来。

**客人常驻**（Q3=b）：来了就不走，直到主人点「送客」。不再有 60 秒 TTL。**不设同屏上限**（Q7）。
- 唯一的自动清理：对方 2 分钟没有心跳（关机/断网/崩溃）→ 客人消失，双方各留一条"对方失联"的记录。
- 我出门在外时，任一条即回家：对方送客、我召回、待满 30 分钟。

**记录**：`visits.json` 照旧，`durationMs` 变成真实停留时长（封顶 30 分钟）；条目上限 200 不变。

**降级**：不是桌面版（web profile）或 helper 起不来 → 宠物不显示，日志一行说明，宿主其他功能不受影响；`dsh-pet` 没装 → 用内置色块，不影响串门。

## 测试决定

沿用 v1：`src/room.js` 是纯状态机、主 seam。v2 新增的两块各自有一层可测的纯逻辑：

1. **出门策略**（纯函数）：输入"现在/上次出门时间/本机活动时间/邻居在线表/开关"，输出"去不去、去谁家"。四条闸门逐条测，尤其是"没活动就不出门"。
2. **桌面场景**（纯函数）：输入"宠物列表 + 时间片"，输出"下一帧位置/朝向/是否越界"。物理不做像素级断言，只断言不变量：不出界、不穿地、拖拽时跟随、松手后有速度。

helper 进程本身不写单测——它只是窗口和 stdio 的壳；它失败的表现是"没有窗口"，用冒烟脚本验。
