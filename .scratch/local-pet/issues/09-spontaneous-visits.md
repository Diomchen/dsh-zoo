# 09: 它自己出门

**What to build:** 宠物自己决定时不时去某位邻居家：四条闸门同时满足才出门（本机最近 10 分钟有活动、距上次出门 ≥ 15 分钟、随机挑中的邻居在线且放行了我、总开关打开）。出门后从自己桌面消失、出现在对方桌面；对方送客、自己召回、或待满 30 分钟就回家。手动按钮「串门」/「召回」随时可用。

**Blocked by:** 08

**Status:** done

- [x] 出门策略是一个纯函数，四条闸门逐条可测，尤其"没活动就不出门"
- [x] 总开关默认关；关闭时绝不自动出门，手动按钮照常可用
- [x] 手动「串门」随机挑一个已放行且在线的邻居；一家都没有时置灰并提示
- [x] 出门期间本机桌面不再显示自己；对方桌面出现它，带昵称
- [x] 送客 / 召回 / 30 分钟三种走法都写一条记录，`durationMs` 是真实停留时长
- [x] 对方失联时（2 分钟无心跳）自动回家并记录"对方失联"

> 完成情况：策略在 `src/visit-policy.js`（纯函数，四道门逐条测）；活动信号 `session/event` 优先、桌面指针兜底；总开关 `auto-visits` 默认关并落盘 `settings.json`；手动「串门」不带 `deviceId` 时随机挑互相放行的在线邻居；30 分钟上限与双向失联都在 `room.tick()`。
