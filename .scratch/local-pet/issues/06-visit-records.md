# 06: 串门记录

**What to build:** 每次串门在双方各留一条记录：谁、什么时候、去了哪、待了多久。点一下访客或邻居灯，弹一张串门卡片，显示最近五条。重启后记录还在。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 一次串门在发起方与接收方各产生一条记录
- [ ] 记录含对方昵称、方向、开始时间、停留时长
- [ ] 卡片显示最近五条，按时间倒序
- [ ] 记录滚动上限两百条，超出丢最旧的
- [ ] 重启 DSH 后记录与卡片内容仍正确
- [ ] 记录文件损坏或不可写时，客厅与串门本身不受影响，只丢记录
