# 03: 第一次见面要点头

**What to build:** 一台新邻居出现时，客厅里出现一行"要不要让它进来"。点接受后它从此自动可见、不再询问；点拒绝后它不再出现，也不再提示。放行之前，本机不向对方发送任何心跳。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 第一次见到某个 `deviceId` 时出现放行提示，带对方昵称
- [ ] 接受后重启 DSH 仍记得，不再询问
- [ ] 拒绝后该邻居不再出现在待放行列表，也不再发送心跳
- [ ] 未放行的邻居收不到本机的任何心跳或串门请求
- [ ] 放行名单与拒绝名单都在本机文件里，可手改可删；删掉后下次见面重新询问
- [ ] 放行名单只按 `deviceId` 认，不按 IP 认
