# 02: 邻居的灯亮起来

**What to build:** 两台机器同时开着 DSH，各自的客厅边缘在五秒内出现对方的邻居灯和名字；关掉其中一台，三十秒内那盏灯淡出。不需要填任何地址。

**Blocked by:** 无（可以立刻开始）

**Status:** ready-for-agent

- [ ] 两台机器在同一网段、都启用插件时，五秒内互相看见邻居灯，名字取对方昵称
- [ ] 关闭一台后三十秒内，另一台的邻居灯淡出
- [ ] 邻居灯最多占一条窄边，六台机器在线时不遮挡主界面
- [ ] 身份来自本机生成并持久化的 `deviceId`：重启 DSH 后邻居认得出是同一台，换了 IP 也算同一台
- [ ] 昵称默认可读（取本机宠物名，没有则取主机名），且能改
- [ ] 广播报文只含协议版本、`deviceId`、昵称、端口；不发送任何项目或会话信息
