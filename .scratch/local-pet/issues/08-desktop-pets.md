# 08: 宠物上台

**What to build:** 占位方块换成真的宠物：自己的那只加上所有客人，在桌面上自由走动、被拖、被扔、撞边反弹。客厅那一整套（浮层、灯、卡片、拖拽出门）删掉。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 自己的宠物按 dsh-pet 的当前动作播放素材，取不到退待机，再取不到退色块
- [ ] 每只宠物有本地坐标和速度：重力、落地反弹、屏幕边缘夹取，不会走出工作区
- [ ] 可以用鼠标拖起来（弹簧跟随感），松手有初速度，能扔
- [ ] 客人以同样方式画出来，带昵称
- [ ] 窗口缩放/分辨率变化后宠物仍在工作区内
- [ ] `shell.overlay` 相关代码与注册全部移除，GUI 里不再有任何宠物元素
