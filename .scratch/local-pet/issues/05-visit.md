# 05: 串门

**What to build:** 我把我自己的宠物拖到某个邻居灯上，它就出现在对方的客厅里，待六十秒后自己走回来；中途我可以召回。对方看到的是"自己的宠物带了个客人回来"。如果对方没放行我，我这边得到一句明确的失败，而不是宠物静悄悄没动。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 拖到邻居灯上即触发出门，不需要二次确认
- [ ] 出门后我这边的本地影子显示"出门了"，并从客厅消失或变暗
- [ ] 对方客厅里出现我的宠物作为访客，持续六十秒
- [ ] 六十秒到期，发起方主动召回，双方同时清理；接收方到期也自行清理，不依赖对方守约
- [ ] 双方都能在到期前召回，召回即时生效
- [ ] 对方未放行时，发起方收到明确失败提示（不是静默无反应）
- [ ] 对方刚断线时触发串门，得到明确失败而不是卡住
- [ ] 超时、无响应、被拒绝三种失败各自有可读的提示文案
