# 11: 桌面上的三个控件

**What to build:** 桌面上只需要三样操作：串门、召回、送客；外加第一次见到新邻居时的一张放行卡。全部画在宠物身边，不回到 GUI。

**Blocked by:** 09, 10

**Status:** ready-for-agent

- [ ] 悬停或点击自己的宠物出现「串门」/「召回」，状态不对时置灰
- [ ] 点击客人出现「送客」
- [ ] 第一次见到某个邻居时，宠物旁边弹一张放行卡（接受/拒绝），不遮挡宠物本体
- [ ] 所有控件只在命中区内接管鼠标，其余地方继续穿透到桌面
- [ ] 串门失败（没放行/不在线/已出门/对方满员）都有一句可读的提示，不静默
