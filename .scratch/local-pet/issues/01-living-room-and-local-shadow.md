# 01: 客厅与本地影子

**What to build:** 打开 DSH 的 GUI，右下角出现一块不挡界面的客厅浮层，里面站着我自己的宠物；它播的动画跟着桌面层那只走。全程不联网。

这是整条链的第一根钉子：先证明"我能在 GUI 里画出一只宠物，而且它是活的"，后面的邻居、访客、串门才有地方发生。

**Blocked by:** 无（可以立刻开始）

**Status:** done

- [ ] 客厅浮层注册进 GUI 的浮层槽位，不替换任何现有条目，整层点穿；只有宠物本体的命中区接收指针事件
- [ ] 客厅里能看到一只宠物，播放的动画与 `dsh-pet` 当前动作一致（同一时刻、同一段）
- [ ] 刷新页面、切换主题、切换会话后客厅仍在，且不报错
- [ ] `dsh-pet` 未安装或未运行时，客厅显示一行说明而不是白屏或异常
- [ ] 宠物不会被主界面遮挡，也不遮挡主界面的可点击区域
- [ ] 无网络时以上全部成立

> 完成情况：dsh-pet 不上报随机待机动画，所以"同一时刻、同一段"只在被点播过的动作上成立；其余时间播插件内置待机片段。见 README 的"已知限制"。
