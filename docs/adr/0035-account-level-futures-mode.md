# 档位下放到账户：谁玩真钱，自己说了算

## Status

accepted（2026-11-18）。取代 [ADR-0032](0032-futures-host-as-clearinghouse.md) 决定 6 里
「整台房主切 `off`/`shadow`/`live` 三档灰度」的 `shadow` 这一档；房主仍保留开市/关市。

## 背景

1.9.0 的期货档位是**市场级**的：房主那台把 `mode` 切到 `shadow`，网络里所有人的期货都变成纸面；
切到 `live` 才是真钱。2026-11-18 早上实测到问题：本机 `role: "peer"`，房主是邻居
`494e6849-…`（`futuresHostId()` 按 `candidates = [selfId, ...futuresPeerIds()].sort()` 取最小 id，
本机 `ac416c63-…` 排在后面），对方停在 `shadow`、`dayCap: 0`——于是本机想开仓被 `daily-cap` 拒，
连纸面都玩不了；想切 `live`，`futures-mode` 只认房主，回 `not-host`。

用户的原话（m05178）：「不对，这个规则要改啊，怎么可能我自己不想玩真实硬币不给切呢」。

## 决定

**档位从市场下放到账户：房主只剩「开市/关市」这一道闸门，每个账户自己选纸面（`shadow`）还是真钱（`live`）。**

1. **账户字段 `accountMode`**：只认 `'shadow'`（缺省）/ `'live'`；与市场闸门 `mode`（`off`/`shadow`/`live`）
   是两个字段、两件事，不共用名字。
2. **自己能切**：HTTP 动作 `futures-account-mode`，body `{ accountMode }`；房主本机就地生效，
   peer 改本地账本同时发 `futures-mode` 报文把选择报给房主，房主记账并随 `futures-settle` 回传。
   切档写一条 `kind:'mode'` 审计流水（`note` 是 `shadow`/`live`）。
3. **钱跟着账户走**：纸面账户充值不动农场硬币、提现不加硬币；真钱账户充值扣自己的农场、提现加回。
4. **两本账不交叉**：撮合按 `orderModeOf` 把挂单分成 `shadow` / `live` 两组，各自与同组撮合；
   做市商对两组都扫单（它是中立的）。这样纸面账户没法用假钱吃掉真钱玩家的单——否则保险基金
   会被「纸面账户稳定盈利、真钱账户稳定亏损」抽干。
5. **纸面的手续费与亏空不进真钱桶**：`#chargeFee(fee, account)` 遇到纸面账户直接返回；
   交割与强平的亏空先看档位，纸面账户不调 `#coverHole`（不花基金、不记 `shortfall`）。
6. **纸面也能正经交易**：原来的「shadow 日额 0」取消，纸面账户与真钱账户同样有 5,000 名义日额、
   20,000 名义持仓上限；只是账是纸面的。
7. **房主的开关只剩两档**：`off`（关市：窗口「期货未开放」、入站丢包、出站不发）与 `live`（开市）。
   旧的 `shadow` 作为房主档位仍被存档读到，含义降级为「谁都没开真钱」，不再顶替交易阶段。
8. **合约状态与档位解耦**：`#sessionOf` 不再有 `shadow` 分支，只报 `trading` / `expired` / `weekend` / `off`；
   档位由窗口单独画徽章。

## 考虑过的选项

- **改选举，让本机优先当房主**：治不了根——只要别人当房主、别人的档位就能卡住你；而且房主是清算所，
  换人等于换账本（`epoch` 变了，历史仓位要重算）。
- **加一个「本机自营期货」的独立市场**：等于两套账本、两套价格，邻居之间反而不能成交，失去意义。
- **让房主配置「谁能开真钱」的白名单**：仍然是把决定权交给别人，和用户的诉求正相反。
- **纸面账户完全禁止交易（保持日额 0）**：用户想「不想玩真钱也能玩」，禁止等于没有纸面档。

## 后果

- 玩家不再需要求房主切档；房主掉线时档位不受影响（本机账本记得自己的 `accountMode`）。
- 真钱与纸面的挂单分成两本盘口，同价时不会互相成交——撮合深度看起来比「全部混在一起」薄，
  但这是安全的代价。做市商仍在，任何时候都有对手价。
- `futures-settle` 多一个可选字段 `accountMode`，老 peer 不发 = `null`（沿用本地选择），协议版本仍是 1。
- 房主作恶空间变小了一点：它仍能关市、仍能算错价，但不能再替别人决定「你今天只能玩纸面」。

## 未定

- 纸面账户的排行榜要不要单独一栏（现在盈亏混在同一张榜里，纸面盈亏是纸面的）。
- 要不要给「从纸面切真钱」加一道确认/冷静期（现在窗口里切真钱有一次 `confirm`）。
