# 项目改名 dsh-zoo，旧名只留在兼容路径里

## Status

accepted — 2026-11-05

## 背景

项目从 `dsh-local-pet` 改名为 `dsh-zoo`。只改标题和包名会留下一个半新半旧的身份：数据目录、
环境变量、helper 开关、本机 HTTP 接口、局域网只读路径里还写着旧名字，用户和脚本都分不清哪套是
现在的约定。

同时有两件事不能靠“改名”顺手丢掉：本机已经积累的身份/放行/串门记录/礼物，以及还在旧版本上的
局域网邻居。前者是一次数据迁移，后者是一条已经在线上的协议兼容。

`dsh-pet` 是另一个插件（名字、动作、皮肤的上游），与这次改名无关，保持原名。

## 决定

- **运行期契约一起换**：npm 包名与插件 id、`index.js` 的 `name`、日志前缀、Electron helper 的
  app 名与 `dshzoo://` 协议、IPC 频道、`--dsh-zoo-*` 开关、`DSH_ZOO_*` 环境变量、本机
  `/dsh-zoo/*` 路由、局域网 `/dsh-zoo-skin/*` 与 `/dsh-zoo-gift/*` 全部换成新名字。
- **数据目录自动迁移**：宿主启动时把 `<DSH_HOME>/local-pet` 整体 `rename` 成
  `<DSH_HOME>/dsh-zoo`。新目录已存在就保持两边原样；`rename` 失败就继续用旧目录，只打一行
  警告——宁可目录名不对，也不能静默换掉设备身份。
- **旧版邻居互通**：UDP 报文里没有项目名，串门协议不动；局域网只读服务同时接受
  `/local-pet-skin/*` 与 `/local-pet-gift/*`，新客户端拉 manifest/素材/文件礼物时也先试新路径、
  404 后再回落旧路径。旧路径只读，不参与广播。
- **本机旧接口不保留**：`/local-pet/*` 是同一台机器上的脚本接口，改名后只提供 `/dsh-zoo/*`；
  不为了几个 curl 长期维护两套路由。
- **升级工具认旧名**：`scripts/install.mjs` 摘掉 profile 里 `dsh-local-pet` 的依赖与 bundles 条目；
  `scripts/uninstall.mjs` 两套都摘；`scripts/stop-helper.mjs` 同时认 `--dsh-zoo-host-pid` 与
  `--local-pet-host-pid`，避免旧 helper 占着包。

## 考虑过的选项

- **只改包名和文档，运行期名字不动**：改动最小，但数据目录、环境变量和路由继续写旧名，等于把
  “改名”永远停在标题上。放弃。
- **彻底断开旧版，不做局域网兼容**：代码最干净，但旧版本邻居的换肤会静默退回通用小人，文件礼物
  会拉不到；串门本身仍然成功，故障是局部的、很难解释。兼容路径只多两条前缀和一个 404 回落，
  换来的是“新旧可以混跑一段时间”。选择兼容。
- **迁移时复制而不是改名**：不会因为半边失败丢数据，但两台机器/两个进程可能各写一份，身份和
  放行名单会分叉。`rename` 在同盘是原子的；失败走“继续用旧目录”，也不分叉。
- **旧本机接口保留别名**：能少改几个脚本，但本机接口是私有的、改起来最便宜；保留只会让新名字
  永远不是唯一入口。选择只换不兼容。

## 后果

- 旧数据目录在成功迁移后不存在；`uninstall` 的数据提示同时提到两个路径，迁移失败的用户不会找不到。
- 旧版本邻居仍能换肤、拉文件礼物：它按旧路径来，新服务端接受；新版本去旧邻居家时先试新路径，
  404 后回落旧路径。两个方向都成立。
- 本机脚本里的 `/local-pet/state`、`/local-pet/action`、`/local-pet/self-state` 需要改成
  `/dsh-zoo/*`；README 与 `docs/protocol.md` 已同步。
- Electron 的 `userData` 随 app 名变化（`dsh-zoo-desktop` 的新目录），里面只有缓存和调试产物；
  窗口位置等非持久状态会重来一次。
- 兼容代码集中在 `src/lan-routes.js`、`src/paths.js` 和两个 fetch 客户端；新增路由时只改这两个
  常量表，不要把旧前缀散回业务代码。
- 回归由 `test/paths.test.js`（迁移与失败回退）、`test/lan-server.test.js`（旧路由可读）、
  `test/skin-fetch.test.js` 与 `test/gift-fetch.test.js`（客户端回落）看住。
