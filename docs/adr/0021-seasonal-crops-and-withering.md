# 四季作物与季末枯萎：只打当季赌注，不动旧资产

## Status

accepted（2026-11-13）。用户选择方案 B：未熟四季作物枯萎、成熟保留、旧六种永不枯萎。
实现票 64 / 66。

前情：[ADR-0020](0020-season-clock.md)（季节时钟）、
[ADR-0019](0019-runtime-crops-over-lan.md)（运行时作物）。

## 背景

季节要改变"种什么"，但不能把玩家已经投入的旧作物变成消耗品。dsh-zoo 的旧六种
（番茄/草莓/胡萝卜/玉米/南瓜/葡萄）是 v1.1 以来全部经济的基础；如果换季全枯，
老玩家一上线就会损失整片地，这是不可接受的。

同时，四季作物需要"当季种、当季收"的时序感：如果跨季还能慢慢长，季节就只是换皮。

## 决定

1. **新增四种四季作物**：豌豆（春，25 分钟）、西瓜（夏，6 小时）、稻米（秋，3 小时）、
   白萝卜（冬，90 分钟）。旧六种数值、生长、价格一字不改。
2. **只在当季种/买**：`farm-plant` / `farm-buy-seed` 对四季作物做季节门禁，错误季返回
   `out-of-season`；卖作物不受限。
3. **当季 +10% 生长**：`seasonGrowthFactor` 返回 1.1；旧六种和自定义作物恒为 1。
   不叠加"跨季 -10%"——因为未熟会枯萎，跨季生长根本不存在。
4. **枯萎方案 B**：换季时，**未成熟的四季作物**变成 `withered`；**已成熟的四季作物**保持可收；
   **旧六种永远不枯萎**。枯萎地不能收/浇/肥，但可以直接重种。
5. **`withered` 是派生阶段**：`plot.withered` 可选布尔；`plotStage` 优先级
   `withered → empty → mature → growing`；`farm.json` 不升版本。
6. **日志合并**：一次换季最多一条 `wither`，带数量和作物，不按地块刷屏。

## 考虑过的选项

- **方案 A：换季全部枯萎（含成熟）**：最像星露谷，但会把玩家留着的成熟作物也收走；
  在 idle 游戏里等于"离线惩罚"；否决。
- **方案 C：都不枯，只是长得慢**：最温和，但季节没有后果，四季作物退化成"四种普通作物"；
  否决。
- **只枯四季作物、成熟也枯**：比 A 轻，但仍会收走玩家算好时间留的成熟作物；否决。
- **给旧六种也加季节**：会重做全部经济与市场深度，且老存档的地会集体失效；否决。
- **枯萎地直接删除/变空地**：玩家会以为bug；保留 `withered` 阶段和"重种"入口更清楚。

## 后果

- 玩家在换季前要决定"收还是赌"；最后 4 小时窗口有明确提醒。
- 四季作物的经济是"当季高产出、错季归零"，旧六种是"稳定但普通"；两套并存。
- 枯萎地不返还种子；重种要重新买/耗种子，形成季节成本。
- 离线跨午夜：未熟四季作物会枯；成熟保留；只补最近 12 小时生长（沿用旧上限）。
- 运行时目录里的自定义作物一律中性；`cropSeason` 只认内置四种，避免 LAN 定义决定本地季节规则。
- 未来加"温室/覆盖物"时，只需让 `#witherSeasonal` 跳过受保护地块；不需要改存档形状。
