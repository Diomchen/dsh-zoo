# 期货市场：房主即清算所

## Status

proposed（2026-11-17）。用户 `/grill-me` 五轮逐条确认；规格见 [SPEC v11](../../.scratch/dsh-zoo/SPEC-v11.md)，票 92–99。

## 背景

盘口（ADR-0028）是一台"对着机器"的机器：价格是 `(作物, 一根, 一格)` 的确定性公开函数，提示直接读本根未来
（实测 96.6% 命中，界面写 55–68%），零费用、亏损封顶、20× 强平线 5% 而 30 万根样本最坏逆行只有 4.54%。
结果是每 50 币 20× 跟提示 ≈ **28,671 币/天**，而本机农场累计才 28,569 币——一天抹平整座农场。
更根本的是它没有对手盘：另一端永远是本机做市商，LAN 只共享一张同样的图。

用户要做的是**真市场**：局域网多人、有对手盘、有成本和价差、会真的被强平、有到期日，
赚的钱来自别人亏的钱。

## 决定

**新增一层独立的 LAN 期货市场：房主就是清算所，每作物一张周合约，公允价锚现货指数，做市商报价 + 玩家挂单，托管账户 + 每根净额结算。**

1. **房主即清算所**：唯一权威账本在房主机器；其他玩家只发意图（下单/撤单/同步），只收结算。
   价格、成交、余额全部房主算。不做 hash 链审计——房主能改文件，链没有真实约束力。
2. **周合约，不做永续**：每作物一张，周一 00:00 上市、周五 20:00 到期；1 张 = 100 个作物；
   交割价 = 19:00–20:00 四根 15 分钟收盘均价的算术平均（防尾盘插针）；默认现金交割，
   玩家可随时"转现货"（按公允价成交现货 + 平掉等量合约，原子两步）。
3. **公允价锚现货指数**：`fair = index × exp(ou)`，`ou` 是均值回归噪声（σ 0.4%、半衰期 30 分钟、
   每 15 秒更新），由散列派生而非 `Math.random`，同一 `(种子, 时间)` 在所有机器可复现。
   做市商在 `fair` 两侧各让 0.2% 连续报价；玩家限价单每根批量撮合（价格优先、同价时间优先）。
4. **托管账户**：钱从农场硬币充进交易所，`balance` 与 `farm.json` 隔离，`marginUsed` 冻结；
   提现原路退回并按 1e6 上限分批（加币超限会静默截断，必须核对实收）。
5. **费用**：taker 0.1% 名义、价差 0.2%×2、交割 0.1%；**90% 销毁、10% 进保险基金**。
   这是它与盘口最本质的区别：长期所有玩家合计是负和的，钱从系统里被抽走。
6. **强平**：1/杠杆，亏损以保证金为限；缺口先由保险基金补，基金空则记账不追债。
   每根按触发价顺序、同价按建仓时间依次执行。
7. **每根净额结算**：不逐笔、不按天。`(epoch, seq)` 幂等；丢包靠 peer 每 30 秒 `futures-sync` 拉取补洞。
8. **准入开放 + 敞口风控**：任何局域网玩家都能开户（用户明确否掉批准制）；补偿：
   单账户日交易额 5,000 币、同时持仓名义 20,000 币、同源地址限速 20 包/10 秒；
   房主在 `futures-hello` 时把 `deviceId` 绑到源地址，之后只认该地址。
9. **三段灰度**：影子模式（不碰 `farm.json`）→ 现金结算 → 实物交割；回滚 = 关窗 + 托管原路退回 + 打 `disabled` 标记。

## 考虑过的选项

- **改盘口规则让提示诚实 / 加资金费 / 加盈利封顶**：治标。实测提示改过去算后命中仍 78%、EV +15.7；
  资金费要 30%/根才抹平。价格生成是确定性的，这个洞堵不住，只能换一层。
- **永续合约 + 资金费**：更像真期货，但没有到期就没有"交割价"这个可信锚，也少了一层玩法节奏；不采用。
- **批准制（`mayTalkTo` 白名单）**：风控最省事，但用户明确要"任何人都能开户"；改为敞口上限。
- **逐笔撮合 / 中央限价簿**：2–6 只宠物、没有常开主机，UDP 无 ack 无重传；每根批量撮合足够，不采用。
- **按天结算**：延迟太久，输赢反馈慢；每根结算。
- **玩家对赌池（零和，无做市商）**：最纯粹，但没有做市商就没有连续报价，开局没人挂单时市场是死的；不采用。
- **hash 链审计**：房主持有文件，链只是自证清白；不采用。

## 后果

- **新协议 5 种 kind**：`futures-hello` / `-order` / `-cancel` / `-settle` / `-sync`；改 `protocol.js` 五处，
  同步协议快照与 `docs/protocol.md`。旧端遇未知 type 静默丢整包 → 新模块必须能独立降级。
- **新存档 `futures.json`**：与 `trading.json`、`market.json` 互不写入；坏文件按空市场运行。
- **新窗口**：独立 focusable 窗口 + IPC，不影响农场窗与盘口窗。
- **房主承担清算职责**：房主掉线 → 市场冻结；10 分钟未回按最后公允价强平并把余额退回各人农场。
  这是这套设计最脆的一环，也是"没有服务器"的代价。
- **钱会真的变少**：费用 90% 销毁，长期负和。玩家要能接受"期货不是印钞机"。
- **风控是软的**：deviceId 可伪造、UDP 无签名，只能靠源地址绑定 + 敞口上限 + 限速；
  恶意玩家仍可刷多个设备。这是局域网信任模型的边界，写进文档而不是假装解决。

## 未定

- 期货窗是否也做成 760×700（暂定沿用盘口尺寸）。
- 单账户日额上限在实物交割阶段是否提高（当前 5,000）。
