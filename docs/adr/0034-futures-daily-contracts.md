# 期货改日合约：一个交易日一张

## Status

accepted（2026-11-17）。取代 [ADR-0032](0032-futures-host-as-clearinghouse.md) 决定 2 里的"周合约"。

## 背景

1.8.0 的期货是周合约：周一 00:00 上市、周五 20:00 交割，一张合约活五天。跑了几天后，用户提出
「一周一张改成一天一张」（m04597），理由是节奏：

- 周合约的第一个问题不是难，而是**慢**。一张合约要等五天才有一次交割，玩的人在中间只能看到
  浮盈亏上下飘，没有"这一局结束了、结算了"的节点。
- 盘口是 15 分钟一局，期货是五天一句，两个窗口摆在一起，节奏差得太多。
- 局域网里一天能遇到的人有限；周合约意味着"周一开的仓，周三才有人接"，撮合稀。

改成日合约后，每个交易日都是一局：开盘 00:00、交割 20:00，当天开、当天了。

## 决定

**每个交易日（周一到周五）一张合约：当天 00:00 上市、20:00 交割；20:00 之后与整个周末都没有可交易的合约。
交割费保持 0.1% 不动。**

1. **窗口**：`contractOf(crop, at)` 用本地日历日：`openAt` = 当天 00:00，`expireAt` = 当天 20:00，
   `[openAt, expireAt)` 之外返回 `null`（`market-closed`）。周六、周日没有合约。
2. **代号**：`<作物>-<YYYYMMDD>`（`tomato-20261117`），日期是本地日历日。旧存档里的周合约代号
   `tomato-2026W47` 仍然能反解（`contractWindowOf`），只为把旧仓位交割掉；新仓单一律日合约。
3. **一晚空窗**：20:00 收盘到第二天 00:00 之间没有任何合约。这是"不能持仓过夜"的直接后果：
   收盘那一根走完所有仓位被交割平掉，挂单被撤、冻结保证金退回。
4. **交割价不变**：仍是 19:15 / 19:30 / 19:45 / 20:00 四根公允价收盘的算术平均。
5. **交割费不变**：0.1% 名义，90% 销毁、10% 进保险基金（用户明确"费用不降"）。
6. **偏离按合约各一条**：`ouDeviation` 的键里带 `contractId`，换合约就是换一条噪声曲线；
   开盘前一小时只有不到 4 小时的记忆，波动天然比收盘时小（热身），这也让每天的开盘价
   与前一天收盘价不连续——这是有意的，不做跨日衔接。
7. **周榜不受影响**：排行榜与"本周盈亏"仍按自然周（`startOfWeek`）清零，和合约节奏解耦。

## 考虑过的选项

- **保持周合约、只是把交割提前**：治不了"五天一句"的节奏问题；不采用。
- **24 小时连续日合约（20:00 交割、20:00 立刻开下一张）**：能持仓过夜，但"一局"变成滚动窗口，
  交割价与开盘价贴在一起，等于永续；而且夜里没人撮合，挂单只是挂着。不采用。
- **周末也开合约**：用户明确"周末不开"。局域网里周末本来没人，开了也是空盘，还要多一套
  "周末合约"的编号与交割；不采用。
- **交割费降到 0.05% 补偿"每天都要交割一次"**：用户明确"费用不降"。日合约的交割次数从每周 1 次
  变成每周 5 次，费用确实变重了——这是设计的一部分：短线越频繁，抽水越多；要少交就少持仓过收盘。
  不采用降费。
- **跨日收盘价衔接（今天开盘 = 昨天收盘 × 隔夜跳空）**：需要额外的状态与广播，且会让"隔夜跳空"
  变成可预测的历史量；不采用。

## 后果

- **仓位活不过一天**：所有仓位在 20:00 被现金交割，或提前平仓 / 转现货。想连续做，得每天重新开。
- **挂单活不过一天**：收盘时未成交的挂单被撤，冻结保证金原路退回（`expireDue` 已有这条路径）。
- **价格不连续**：每天开盘是新的偏离曲线，开盘价相对昨收的跳空会比周合约时更明显。
  窗口与文档都写"今天 20:00 交割"，不会让人误以为还有"下周"。
- **交割次数 ×5**：一天一次的现金交割 + 0.1% 交割费，短线的摩擦成本变高；这是有意的负和设计。
- **测试与夹具全部换成"工作日某天"**：任何用 `Date.UTC` 构造的固定时刻在东八区可能已经过了 20:00
  （`Date.UTC(...,12,0,0)` = 20:00 CST，正好收盘），夹具一律用本地 `new Date(y, m, d, h)`。
- **协议兼容**：`FUTURES_CONTRACT_RE` 同时接受 `\d{8}` 与旧的 `\d{4}W\d{2}`，旧端收到的日合约编号
  会被旧正则拒绝——所以这次是**协议语义变更**，两台机器都要升级才能互相看到仓位。
- **周榜与日合约并存**：一天五局，但排行还是一周一结算；想按天比，得另做一个日榜（未做）。

## 未定

- 周末是否给一个只读的"上一交易日回顾"窗口。
