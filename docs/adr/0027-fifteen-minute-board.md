# 盘口：15 分钟合约、农场硬币、真人榜

## Status

proposed（2026-11-16 按用户三条口径收口；等 SPEC v10 与票 79–83）

> 编号说明：本线是**盘口**——ADR-0027 / SPEC v10 / 票 79–83。
> SPEC v9 与 ADR-0024–0026 是同一天另三条线（露水 / 铲地 / 自适应行情），不要混。

规格：[SPEC v10](../../.scratch/dsh-zoo/SPEC-v10.md)
原型：[exchange-15m-board.html](../../.scratch/dsh-zoo/prototype/exchange-15m-board.html)
（手感参考；里面的赛季筹码、手续费、NPC 都是占位，正式实现按 SPEC v10 改）。

## 背景

交易所到现在还是「自己的商店 + 一条 15% 的指数」：买卖的另一方永远是本机做市商，
邻居只贡献一个中位数。上一版「跑一趟」想把乐趣押在跨机背货上，但没人买货、价差不对，
交易所就空了——乐趣依赖别人。

用户要的是：**15 分钟一根、随机但有趋势、能做多/做空、重交易轻过程；真邻居；
不搞风险控制（输了就老老实实种地）；结算简单；限价/止损可选。**

## 决定

**盘口是一层独立于现货的 15 分钟合约：农场硬币下注，行情由确定性种子生成，
LAN 只做同一张图和真人榜，不做对手盘。**

1. **行情**：15 分钟一根 K 线；慢趋势（约 4–6 根一段）+ 快噪声；价格锚在作物底价，
   夹在底价的 0.55–1.75 倍；同一 `slot + crop + 版本盐` 在所有机器上算出同一张图，
   不需要服务器。风向提示只给慢趋势方向和 55–68% 的置信度，快噪声会把弱信号打反。
2. **结算只有一条公式**：
   - 做多：`盈亏 = 保证金 × 杠杆 × (现价 / 入场价 − 1)`
   - 做空：`盈亏 = 保证金 × 杠杆 × (1 − 现价 / 入场价)`
   - 强平：做多 `现价 ≤ 入场 × (1 − 1/杠杆)`，做空 `现价 ≥ 入场 × (1 + 1/杠杆)`；
     亏损上限就是保证金。
   - 没有手续费、没有资金费、没有 0.4% 缓冲、没有追保；15 分钟收盘自动结算，
     也可以随时手动平仓。UI 只显示「涨 1% = ±X 币」。
3. **用农场硬币下注，不搞风险控制**：没有赛季筹码、没有单笔/总仓位上限、没有保险、
   没有重置。保证金从硬币里锁，收盘把「保证金 + 盈亏」退回硬币；硬币到 0 就不能再下单，
   只能去种地。农场自己的露水/种子/节日兜底不动——那是农场的循环，不是交易的保护。
   一次 20× 强平可以清空硬币；这是真钱感的一部分。
4. **真邻居，不搞 NPC**：盘口不依赖任何人成交；邻居只上报自己的
   「本周交易盈亏 + 当前持仓（作物/方向/杠杆）」，由 `trading-digest` 每 30 秒 gossip 一次。
   榜上是真人；没邻居就自己一个人，行情照走。旧邻居静默忽略新报文。
5. **可选工具，不破坏轻过程**：
   - 持仓卡上一键止损：关 / −25% / −50% / −100% 保证金，到线自动平仓；
     这是玩家自己设的工具，不是系统强加的风控。
   - 到价开仓（限价）放 v1.5：目标价 + 挂单，15 分钟收盘没成交就撤；不做部分成交、
     不做订单簿。先做一键止损，别把下单区做成表单。
6. **窗口**：盘口单独一扇 focusable 窗口（约 760×700），不塞进 520×700 的农场窗；
   桌面右键 / 农场窗里的入口打开。图表、下单、持仓、周榜都要宽度。
7. **周榜**：本周交易盈亏（金币）排序，旁边留一列收益率；
   每周一 00:00 清零的是「本周盈亏」这个分数，不是硬币。硬币亏掉就是亏掉。

## 考虑过的选项

- **赛季筹码（人人 1,000）**：公平，但和「输了就老老实实种地」冲突，也让输赢不像真的；
  不采用。
- **NPC 填榜**：热闹，但用户明确要真邻居；不采用（原型里的 NPC 只用于演示布局）。
- **手续费 / 资金费 / 单笔风险上限 / 保险**：用户明确不要；不采用。
- **中心订单簿 / 实时撮合**：2–6 只宠物、没有常开主机；盘口自己走行情就够，不采用。

## 后果

- **真钱感**：硬币会真的少；20× 可能一把清空。农田是唯一退路，玩家要能接受。
- **榜可能被硬币多的人占据**：不额外做公平性限制；收益率列只是展示，不改排序。
- **行情可预计算**：种子公开，懂代码的人能算下一根；不做强防作弊（和 ADR-0016 一致）。
- **新协议 / 新文件 / 新窗口**：`trading-digest`；`trading.json`（持仓、挂单、本周盈亏、
  历史）；盘口窗口；桌面入口；旧邻居降级。
- **离线补结算**：行情是算出来的，关掉 DSH 也能按收盘价补结算；持仓不会因为离线消失。
- **止损/限价是本地的**：不跨机、不托管；对手盘始终是做市商。
- **盘口和现货互不影响**：现货交易所继续管种子的固定价、作物的 bid；盘口是另一张图，
  不改变 `farm.json` / `market.json` 的现货规则。

## 未定

- 到价开仓放 v1 还是 v1.5（SPEC v10 默认 v1.5）。
- 止损预设是 −25/−50/−100 还是别的档。
- 周榜按盈亏还是收益率排序（SPEC v10 默认盈亏，收益率只展示）。
- 盘口窗口的确切尺寸与入口（右键 / 农场窗页签）。
- 快噪声的具体幅度与趋势换挡频率（1 小时 / 2 小时）。
