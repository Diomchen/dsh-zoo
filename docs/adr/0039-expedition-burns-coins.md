# 出远门：用一条净烧八成盘缠的路给硬币出口

## Status

accepted

## 背景

50 块地买满以后，农场一天进账 28,000 左右，而硬币的出口只剩三个：种子（一天几十）、
雇工（一天不到 30）、盘口保证金（不销毁，只是换个地方放）。当前存档堆到 37 万，
上限 1,000,000 一到，收入就在 `src/farm.js:1912` 的 `Math.min(MAX_COINS, before + qty)`
处被静默截断。

红包是转移不是销毁（一天上限 600），期货通道坏着且日额只有 5,000 名义。也就是说：
**这个经济里没有任何一处会把大额硬币真的烧掉。** 「出远门」补的就是这一处。

## 决定

- **硬币是净烧的**：盘缠入场即扣、不退；每段回币 = 盘缠 × 3%（±25% 抖动），
  特产不能卖。期望净烧 **80.5%–89.5%**，随路线变短而变高（见 `docs/play-expedition.md`）。
- **四条路线，四档盘缠**：后山 500 / 废矿 3,000 / 老铁路 15,000 / 雾岭 60,000。
  首尾差 120 倍，覆盖「随手玩一把」到「认真烧一次」，雾岭一把约等于两天收入。
  第五条「海外」留扩展，v1 不做。
- **特产不可售**，这是地基：可售就变成刷钱路线（雾岭一把回 12,600，一件特产值 3 万就崩）。
  特产能陈列、进图鉴、v2 能塞红包送人，但换不回一个硬币。
- **一趟最多 7 段、一次 2–5 分钟**：每段走路 20 秒 + 决策窗 20 秒；**关掉窗口也照走**，
  超时未点按「见好就收」处理——不为一个挂机小游戏扣住玩家的注意力。
- **翻车不额外惩罚**：特产随机丢一半、硬币按已走段数照给、盘缠不退，立刻回家，**没有冷却**。
  冷却会掐死这个唯一的高频销毁入口。
- **同一时刻只能一趟**，但**没有连刷冷却、没有每日次数上限**：防刷不靠闸门，
  靠「回报永远小于盘缠」这条数学。
- **v1 的升级只留两样**：提灯 10,000（显示精确危险度，默认只给低/中/高）、
  陈列架格 5,000/格。背包、靴子、护身符砍掉——一条路线只有 8 件、一趟最多 7 段，
  背包不会真卡；靴子是卖「缩短等待」；护身符 500 对 60,000 的雾岭等于花 0.8% 免掉翻车，
  会把紧张感抹平。
- **代码切两个文件**：`src/expedition.js`（规则 + 路线/掉落常量，纯函数，`now` 与 `rng` 由参数传入）
  与 `src/expedition-store.js`（json 读写、种子 RNG、损坏修复、快照）。
  动作前缀 `expedition-*`，与 `farm-*` / `trading-*` / `futures-*` 并列。
- **v1 不碰协议**：只在本机跑，特产不跨设备同步；红包塞特产留 v2，数据结构先留 `giftable: true`。

## 考虑过的选项

- **村口功德碑**（捐钱刻名，1k/1万/10万/100万四档，最高档立金宠物像）：
  纯销毁、贵、社交展示也够，但**一次性**——刻完名就没有第二次点开的理由，
  对「一天 2.8 万进账」的现金流来说，它只能烧掉一杯水。
- **赌石摊**（1k/1万/10万三档原石，切开看种水）：开箱手感好，但本质与盘口同质
  （都是「押一笔、看随机、按倍率结算」），而且极品要能变现才有意义——一变现就变刷钱。
- **盘口加杠杆 / 提高盘口上限**：盘口是印钞机不是赌场（PnL 按模型价结算，赢=造币、输=烧币），
  加大它只会让经济更通胀。
- **期货扩容**：费用确实烧 90%，但 peer→房主的写通道坏着（充值/平仓只回 pending，钱会凭空消失），
  且日额 5,000 名义，量级差两个数量级。
- **红包加额度**：转移不是销毁，加额度只是让硬币在邻居之间搬家。
- **v1 就做满升级线（背包三档 / 靴子 / 护身符）**：背包在 8 件/路线的结构下不会卡；
  靴子把 20 秒变 10 秒，卖的是等待时间不是内容；护身符让高风险路线失去风险。
  三样都是「为了卖升级而造需求」，先砍，等真有人嫌慢再说。

## 后果

- 硬币第一次有了**可重复、有随机、有收集、有展示**的销毁口；农场从「两个转移口 + 一个印钞机」
  变成「有真出口」的经济。
- 烧掉 37 万需要约 840 趟后山或 8 趟雾岭——不会自己消失，但真想花就有地方花。
- **已知问题不修**：1,000,000 上限处的收入静默丢失仍在（`src/farm.js:1912`）。
  它属于农场经济的基础改动，会牵动盘口、期货、红包的所有换算，而这轮的目标是给硬币出口，
  不是重做上限。文档里记一笔，留待单独一票。
- 新增 32 张特产 SVG（`desktop/souvenirs/`，合计 25.5 KB）与一个新窗口；
  美术规格沿用 `desktop/crops/*.svg`（100×100、单层 10% 投影、纯色 path、无渐变），
  缺图回退 `emoji`，不会开天窗。
- 特产一旦将来能卖或能换钱，整个平衡立刻失效；**「不可售」要写进代码注释与验收清单**，
  避免下一个人「顺手」加一个卖特产的按钮。
