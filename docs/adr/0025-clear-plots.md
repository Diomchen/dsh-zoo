# 铲除：给种错/冻住的地一个免费的止损出口

## Status

accepted（2026-11-16）。用户问“铲除的功能要不要实现？”，选择推荐的小范围方案。
实现票 77。

前情：[ADR-0021](0021-seasonal-crops-and-withering.md)（枯萎）、
[ADR-0023](0023-frozen-plots.md)（冻住）。

## 背景

地块只有“种下”和“收获”两个出口。种错季节、想换作物，或者冬天地块被冻住但不想付
2 露水 + 5 硬币解冻时，玩家没有低成本退出方式：要么等成熟，要么付解冻费，要么
让四季作物换季枯萎。访客/看田也不该有这种权力。

## 决定

**新增 `farm-clear`：只清生长中或冻住的作物，免费、不退种子、不产作物；两段点击确认。**

1. **允许**：`growing` 和 `frozen`。冻住的地清掉后直接变空地，省下解冻费，但作物同样消失。
2. **拒绝**：`mature` 返回 `plot-mature`（先收割）；`withered` 返回 `withered`
   （枯萎卡本来就能点一下重种）；空地返回 `plot-empty`；未知地块 `bad-plot`。
3. **代价**：免费，不退种子、不给作物、不扣露水/硬币；只记一条 `clear` 日志，带作物 id。
4. **权限**：只有主人视图显示；访客/看田没有铲除动作。宿主动作名 `farm-clear`，只带 `plotId`。
5. **确认**：窗口第一次点只把按钮改成“确认铲除？”，4 秒内再点才发请求；重画/超时自动复位。

## 考虑过的选项

- **允许铲成熟作物**：等于“免费销毁”，容易误触，且收获本来就是正面动作；否决。
- **收手续费/退部分种子**：要新增定价与退款规则，收益很小；否决。
- **铲除后直接弹出播种**：多一步联动，先保持单一动作；否决。
- **只允许铲冻住的地**：种错季节的止损需求同样真实；扩大到生长中。

## 后果

- 玩家可以主动放弃一株作物来换季节/换布局，不需要等它成熟或枯萎。
- 冻住的地多了一个“不付解冻费”的出口，冬季来客的惩罚仍成立（作物没了）。
- 不新增地块阶段、不改 `farm.json` 版本、不进 LAN 协议；只多一个动作和一条日志。
