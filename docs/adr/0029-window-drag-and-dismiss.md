# ADR-0029：盘口窗可拖动，点窗口外面收起所有插件窗

**Status:** accepted
**Date:** 2026-11-16

## Context

盘口窗是 760×700 的居中窗口，`movable:false`：挡桌面又挪不开。同时从 ADR-0005 起，
所有插件窗（农场 / 带派 / 改名 / 盘口）都**故意不在 blur 时关闭**——macOS 上中文输入法的
候选窗会抢走键盘焦点，按 blur 关窗会变成「打中文时小窗消失」（`desktop/main.js` 多处现场注释）。

用户 2026-11-16 明确要求：窗口可以拖动；点窗口外面区域，所有窗口消失。这与旧的
「不按 blur 关」直接冲突，需要一条新决定。

## Decision

1. **盘口窗可拖动**：标题栏 `-webkit-app-region: drag`，交互元素 `no-drag`；
   位置写进 `userData/board-window.json`，重开恢复并夹进当前工作区，坏文件/离屏回落居中。
2. **点外面收起所有插件窗**：任一插件窗失焦后等 200ms，如果焦点没有落到另一扇插件窗，
   就收起盘口、农场、带派、改名四扇窗。延迟用来躲开「打开另一扇窗」的瞬时失焦。
3. **输入法保护**：窗口在 `compositionstart`..`compositionend` 之间失焦不收起；
   冒烟用的 blur 锁同样跳过。这是旧约定的唯一保留部分——不是「永不关」，而是
   「正在输入时别关」。
4. **合约不受影响**：图表的 15 分/1 时/1 日/1 周只是看盘；结算仍然只认 15 分钟收盘
   （票 84）。

## Consequences

- 旧注释「不要按 blur 关窗」作废，改成「composing 期间不关」。
- 改名/带派里打中文时点外面，窗口会留到 composition 结束；这是可接受的折中。
- 多显示器/分辨率变化后，盘口窗位置会夹回可见工作区。
- 窗口位置只记盘口；农场/带派/改名仍按各自规则出现（暂无拖动需求）。
