# ADR-0033：盘口降温——5× 上限、名义费、5% 维持保证金、随机游走行情

**Status:** accepted
**Date:** 2026-11-17
**Supersedes:** ADR-0030 的「多尺度慢波」价格模型（其余部分仍有效）

## Context

盘口上线后周榜出现 `+80298` 这种分数。查下来不是技术好，是两件事叠在一起：

1. **本金越大分数越高**。榜按本周盈亏**金币绝对值**排序（`src/trading-league.js` 的
   `compareRows`），59 万本金的账户随手做一手就顶别人一周。
2. **行情可预测**。`hintOf` 读的是 `slowLevel(slot+1) - slowLevel(slot)`——下一根慢趋势的
   斜率，等于把答案印在屏幕上。实测跟随提示：每手 +11.46 币、胜率 97.2%；即使按「第 5 分钟
   进场、持到收盘、5×、扣 0.4% 名义费」这种保守口径，仍有 +7.01 币/手、95.6% 胜率。
   一块地每小时净收益 5.7–28.8 币，一手 100 保证金就顶一块地，而盘口随本金线性放大。

用户要求「本质没人种地」这个问题要解决，并选定 **1+4**：价格改成不可预测的过程 + 周榜按收益率
排序。零和撮合（方案 2）与「本地确定性价格 + 离线补算」冲突，留作第二刀。

## Decision

1. **杠杆收到 1×/5×**（`TRADING_LEVERAGES = [1, 5]`，`MAX_LEVERAGE = 5`）。读盘白名单另设
   `LEGACY_MAX_LEVERAGE = 20`：盘上已有的 20× 仓位仍能读回、仍按 20× 结算与强平，但新开仓
   只认 1×/5×。
2. **开平各 0.2% 名义费，结算时一次扣清**：`fee = tradingFeeOf({margin, leverage}) × 2
   = round(margin × leverage × 0.002) × 2`。开仓只扣保证金（不让「差 1 个硬币付手续费」把单
   挡在门外），平仓从回款里扣，`credit` 下限 0。本周盈亏按**净额**累计。
3. **5% 维持保证金**：强平线 `入场 × (1 − 0.95/杠杆)`（做空相反）。强平**按强平线成交**，
   不用撞线那一分钟的插针价——否则 20× 一格跳空能穿透好几个点，「5% 维持」名存实亡。
   先判强平再判止损（交易所规则优先）。
4. **价格过程换成 v4 分钟级随机游走**（`PRICE_SALT = 'board-v4'`）：
   - 每分钟一个独立增量，σ = 0.52%，单根 σ ≈ 2.0%；
   - 弱 OU 回归（`WALK_PULL = 0.0009`，半衰期约 13 小时，稳态 σ_log ≈ 0.12），把价格压在
     `base×0.55`–`base×1.75` 的夹子内部，实测一年贴夹率 0%（旧模型 7–17%，还出现整段不动）；
   - 1 分钟之内价格恒定、不插值：插值等于把下一分钟的方向提前印在图上。
5. **风向改成「最近三根已实现动量」**，文案写明不预示下一根；置信度仍 55–68%。
6. **周榜按收益率排序**：`weekPnlPct` 降序；没有收益率的行（旧邻居周报不带这个键）排最后，
   再按金币降序、昵称、deviceId。窗口里收益率是主数字，金币退成副标题，名次写在昵称前。
7. **费率随包下发**（`limits.feeRate`），下单区常驻一句「开平各 0.2%」。

## Consequences

- 5× 的强平线是 19%，单根走不到（最大逆行 9.09%）→ **新开的 5× 仓位实际上不会被强平**；
  强平只会发生在盘上遗留的 20× 仓位上。25% 止损档需要 5% 逆行（约 0.1% 的根），止损基本是
  玩家工具而不是系统风控。
- 跟随提示 / 反向提示 / 永远做多三种策略，实测每手 −1.90 ~ −2.12 币（≈ 手续费），胜率约 40%
  ——没有方向能带来正期望。
- 旧图作废（salt v4）；ADR-0030 的「日/周线读得出趋势」验收不再成立，测试改成钉「振幅随
  窗口按 √N 放大」。
- 协议字段没变：`trading-digest` 早就带 `weekPnlPct`；只新增了 payload 里的 `limits.feeRate`。
