# 农场经济：本地账本、联邦行情、宠物背货

## Status

accepted

规格：[SPEC v5](../../.scratch/dsh-zoo/SPEC-v5.md)；票 39–45 在
[`.scratch/dsh-zoo/issues/`](../../.scratch/dsh-zoo/issues/)。

## 背景

用户要「农场模式」：种地、待机生长、去邻居家偷菜、有交易所、还能雇佣别人的宠物看家。
串门到现在只交换「我是谁 / 我在干嘛 / 我说一句」和单向的礼物（ADR-0011），没有货币、
价格和长期目标。农场是第一个真正的经济层。

四条约束决定了它的形状：

1. **没有中心服务器**：发现、串门、礼物都是 P2P；加一台交易所主机就多一个必须常开的
   地址、一个信任面和一套故障模式。
2. **局域网通常只有 2–6 只宠物**：玩家挂单的订单簿大部分时间是空的，撮合深度不够。
3. **UDP 一包 4 KiB，桌面主窗不能打字**：农场数据不能塞进心跳；操作得另开 focusable 小窗。
4. **不做强防作弊**：邻居能改自己的 JSON；经济能防误操作和刷屏，防不了恶意复制。
   所以「中心化」买不到安全，只买一致性。

## 决定

**农场是本地的，交易所是联邦的，结算是宠物背的。**

1. **农场本地**：每台机器一份农场状态（地块、仓库、硬币、露水、合同），没有全局余额，
   也没有跨机账本。农场属于身份，换皮、改名都不动。
2. **交易所联邦**：每个农场一个本机做市商（买种子、卖作物，永远有流动性）；价格随本机
   供需浮动；每 30 秒把本机价格广播给放行邻居，各家取中位数混成「局域网行情」。
   成交在本机完成，不做中心主机，也不做分布式订单簿。想按邻居的价格成交，得派宠物把
   货/币背过去——价格差就是背货套利的机会。
3. **结算物理**：硬币和作物只有在宠物驮包里时才跨机。工资、偷来的作物都走驮包；
   跨机结算用幂等报文补发，但没有跨机账本、没有托管所、没有中央余额。
4. **偷菜永远允许**：放行邻居 + 活跃串门 + 成熟作物就能偷；只受每日上限和守卫影响。
   不做「谢绝偷菜」开关，也不做保护期——这两样都会让偷菜失去意义。
5. **雇佣是合同**：主人挂牌定价；雇主预付工资到宠物的驮包；雇工在雇主农场进入
   `working` 状态，合同期内不住自己家，所以**自家农场没人看**。合同 2–8 小时，
   可以提前召回，按实际时长结算；v1 一个雇工位。
6. **守卫**：自家宠物在家 + 雇工，按守卫值降低偷菜成功率并可能抓住小偷；不做完全免疫，
   也不做罚款。被抓的代价只是这次白跑。

## 考虑过的选项

- **中心化交易所主机**：一致性强、能做订单簿，但单点故障、要运维、要看主机脸色；
  而且它防不了改 JSON，只买一致性。2–6 人不值。
- **分布式订单簿**：每台机器复制挂单、gossip 撮合。复杂、流动性低、冲突难调试；
  一个陪伴型桌宠不需要一个交易所级别的状态机。
- **纯本机商店**：最简单，但邻居的供需影响不到你，交易所只是个商店，不像「交易所」。
- **数字账本 + 转账回执**：可行，但要处理丢消息、重复结算和双花；在「不做强防作弊」
  的前提下，物理驮包更贴合宠物/串门，也更容易解释。
- **「谢绝偷菜」开关 / 成熟保护期**：会把偷菜变成可关闭的骚扰，用户明确不要。
- **远程守卫**：省美术，但没有「雇来的宠物在院子里巡逻」的画面，也失去「自家没人看」
  这个真正的代价。

## 后果

- **最终一致**：各家价格会短暂不同；这不是 bug，是背货套利的机会。强一致只存在于
  单机内部。
- **跨机价值转移是异步的**：偷菜、工资、结算都要按 `requestId` / `contractId` 幂等，
  带重试和上限；丢消息时最多「这次白跑」，不能双花。
- **偷菜永远开**：收菜要及时、出门要留人；雇工是主防线。主人能看到是谁偷的，可以偷回去。
- **新 UI 面**：桌面上一小块地 + 一扇 focusable 农场小窗（交易所/雇工/记录）。
  v1 用 emoji/SVG，别等像素素材。
- **旧邻居不参与**：新报文旧版本静默丢掉；串门、礼物、记录照常。降级表要写清楚。
- **离线即暂停**：没有中心服务器，对方离线就不能偷/帮/雇；合同按最后心跳结束并结算。
- **新文件、新报文、新限额**：`farm.json` / `market.json` / `contracts.json`；
  `market-digest` / `farm-action` / `work-*`；票 39–45。
