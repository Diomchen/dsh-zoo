# 盘口行情 v5：波动率聚集、消息面与 LAN 真人流

## Status

accepted（2026-11-18）。用户按 [PROPOSAL v12](../../.scratch/dsh-zoo/PROPOSAL-v12-market-feel.md)
的推荐方案批准；先落 A 期（行情 v5 + 消息面 + 关键 K hover），B 期（LAN 资金流）在 A 期稳定后接。
规格见 [SPEC v12](../../.scratch/dsh-zoo/SPEC-v12.md)，票 103–108。

## 背景

盘口 v4（[ADR-0033](0033-board-fair-pricing.md)、票 102）是常方差分钟随机游走：
每分钟 σ 0.52%，15 分钟 σ ≈ 2.0%；实测一年峰度 ≈ 2.9、波动率自相关 ≈ 0、贴夹率 0。
它是为了堵住"读下一根"的套利而刻意做成鞅的，代价是**每根 K 线的大小都差不多**：
没有安静/狂暴的分别，没有消息造成的跳空，也没有邻居下单推动行情的体感。

用户要的是"真实市场体验"：波动要有形状，消息面要有故事（关键 K hover 能看见发生了什么），
局域网里每个人的操作要对 K 线有中等影响。三者都不能把票 101/102 修好的洞重新打开。

## 决定

**价格改成三层，一个入口：`price = clamp(base × exp(W + N + F))`；A 期先做 `W` 与 `N`，
`F` 预留接口、B 期接 LAN。**

1. **v5 底盘 `W`**：在 v4 随机游走上加三个**只改幅度、不改方向**的乘子：
   - `session`：按固定市场时间（UTC+8）的双峰曲线，早/晚高、凌晨低；
   - `regime`：多尺度平滑的波动率聚集（约 47 分钟 / 3 小时 / 11 小时 / 30 小时），
     夹在 0.62–1.55；
   - `storm`：消息"不确定性"事件期间 1.6–2.2，持续 15–45 分钟。
   另加罕见的肥尾跳跃（平时每 1–2 天一次 3–6%，稀有的 6–10% 黑天鹅），
   跳跃在 1 分钟格点上**一次性完成**，不做平滑衰减。
   目标：15 分钟 σ 2.3–3.0%、峰度 4–8、波动率自相关 0.10–0.30、收益自相关 |ρ| < 0.03、贴夹 < 0.05%。
2. **消息面 `N`**：`src/board-news.js` 由 `(salt, crop, marketDay)` 确定性生成事件表；
   每个作物每天 4–6 条，另有全市场 2–3 条/天；每天 5 个固定日程（09:30/12:00/15:00/20:00/22:30），
   提前 10 分钟预告、公布时跳价。
   - 消息在**公布那一分钟**一次性定价；`N` 按 72 小时半衰期缓慢淡去（单根 < 0.01%），
     不做"利好持续 N 分钟"的平滑趋势。
   - 传闻/证实是两次独立跳跃（方向 50/50 或证实幅度 < 辟谣幅度），保证追消息期望 ≤ 0。
   - 关键 K（头条/黑天鹅/传闻、|涨跌| ≥ 4% 或近 24 根前 3、巨鲸单）画旗子；
     hover 便签加"消息面 / 资金流"两行；点开详情卡；图头下 16px 快讯条。
3. **LAN 资金流 `F`（B 期）**：
   - 每个人的开/平/止损/强平发一条 flow 事件；`u = 0.003 × dir × sqrt(min(notional,5000)/500)`，
     单笔 ≤0.6%、单设备单根 ≤1.2%、单日 ≤4%、每作物 `F` ≤1.5%，2 小时半衰期。
   - 成交价含一半自身冲击：往返自身冲击净额 ≈ 0，自买自卖赚不到自己的冲击；
     收盘结算不补流水（纸面收益上限 0.3% < 0.4% 往返费）。
   - 传播走 **P2P 事件带**（`board-flow` / `board-flow-sync`），无房主；
     正常 1–2 秒一致，极端丢包窗口内可能差 ≤1 笔；结算留 2 秒宽限。
   - 跨系统来源（期货/农场）在 C 期以更低权重接入，不合并账本。
4. **迁移**：`PRICE_SALT` 升 `board-v5`；`trading.json` 版本 1 → 2，保留 week/positions/orders/history，
   新增 `flow` 空壳；未平仓位按新行情 **re-base 入场价**，PnL 从 0 开始，日志记一条"行情版本升级"。
   这是用户批准的取舍：不让一次行情升级把老仓位按一张它们没见过的图结算。
5. **分阶段**：A（票 103–106）纯本机，先解决"温和、单一"；B（票 107）接 LAN 流；
   C（票 108）做日程抽屉、LAN 快讯、跨系统来源与调参。A 不碰协议，B 才改协议。

## 考虑过的选项

- **加趋势/正弦慢波让图"好看"**：票 102 已证明会被读成 96% 胜率；不采用。
- **消息后做平滑衰减/持续漂移**：会让"消息后反着做"变成可预测回撤；不采用。
- **消息只展示、不影响价格**：K 线上的跳空与消息对不上，且用户要的是"影响因子"；不采用。
- **用 LAN 情绪（多空计数）代替逐笔流**：每 30 秒才更新、不区分大小，手感迟钝；不采用，
  但保留情绪面板作为辅助展示。
- **房主严格顺序**：结算最准，但盘口必须单机可用、邻居掉线不停摆；不作为第一版，
  留作 D 期的可选"房主行情"。
- **资金流按全额滑点**：真实但惩罚过重；半滑点已能让往返自身冲击净额归零。
- **联网/AI 实时新闻**：破坏可复现、离线可用和隐私边界；不采用，固定模板足够有趣。

## 后果

- **图全变**：`PRICE_SALT` v5，所有 15 分钟/1 时/1 日/1 周图作废；结算价随之变化。
- **老仓位要迁移**：re-base 入场价，不按新图补算旧盈亏。
- **载荷变大**：bar 增加可选第 8 项 `news`，窗口包增加 `news`/`calendar`；
  体积估算 < 32 KiB，仍远低于 256 KiB IPC 上限。老窗口忽略未知字段，老宿主不画消息。
- **UI 变高**：图高 228 → 212，给 16px 快讯条；卡片总高不变，下两列不动。
- **新增测试面**：行情形状（σ/峰度/波动率自相关/收益自相关）、消息确定性/文案/密度、
  载荷归一化、便签/标记/快讯/详情的纯视图、v5 迁移。
- **B 期的诚实边界**：P2P 流不是强一致；LAN 无签名，伪造事件只能被单笔/单设备/单根上限限制。
  这两条写进 README，不假装解决。
- **期货不受影响**：盘口的 `boardPrice()` 与期货的 `fairPriceOf()` 仍是两张图；
  跨层联动留到 C 期，且要单独决策。
