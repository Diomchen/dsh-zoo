# dsh-zoo 1.6.4 更新说明

## 修复

- **Windows 上「宠物突然拖不动」不会再一直卡住。** 偶尔会出现：宠物画着、右键菜单也能开，
  但左键按下去完全没反应，拖不动也点不动，过一阵又自己好了。根因是「窗口可交互」这个状态
  有时候没真正落到系统层，而主进程看到状态没变就不再重试，于是一直停在假可交互上
  （2026-11-04 那次现场要靠右键「重载配置」重启 helper 才恢复）。

  现在有两道兜底：

  - 可交互期间每 2 秒把同一个状态重新落一次，落不上就自己补上；
  - 万一还是丢了左键按下（只收到松手、没收到按下），自动重放一次「穿透 → 可交互」，
    不用重启 helper，也不用把鼠标移开再移回来。

- `/dsh-zoo/desktop` 多三个数，下次现场好对账：`lostDowns` / `reasserts` /
  `windowMessages`（Windows 上窗口真实收到的左键、右键消息条数）。

## 兼容

- 只动桌面 helper 的输入兜底；不改 LAN 协议、不加 UDP 报文，`farm.json` / `season.json` /
  `contracts.json` 都不升版本。
- 回退：装回 1.6.3 即可，没有数据变更。
