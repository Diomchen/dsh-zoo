# dsh-zoo 1.7.0

盘口上线：拿农场硬币押 15 分钟涨跌的小盘口。它不是现货交易所的改版，而是独立的一层——
现货照常买卖作物，盘口只做「15 分钟一根」的合约，行情自己算，不依赖任何人成交。

## 盘口窗

- 桌面右键「盘口」，或农场窗顶部的「盘口」按钮打开；约 **760×700**，可拖标题栏移动，
  位置记在 `userData/board-window.json`，重开恢复并夹回工作区。
- 点窗口外面（桌面 / 别的应用 / 宠物）收起盘口、农场、带派、改名四扇窗；输入法合成期间
  不收起（[ADR-0029](adr/0029-window-drag-and-dismiss.md)）。
- 窗口里：作物条 + 周期（15 分 / 1 时 / 1 日 / 1 周）、K 线（价格轴 / 时间轴 / 十字线 OHLC）、
  图下全宽下单横条、持仓与最近结算、真人周榜与 LAN 情绪。

## 合约与结算

- 一根 = 15 分钟 = 15 个 1 分钟 tick；价格锚作物底价，夹在 `base×0.55`–`base×1.75`。
- 做多 / 做空，杠杆 1× / 5× / 20×；保证金预设 50 / 100 / 250 / 全下（宿主 / HTTP 也接受
  1–1,000,000 的任意整数）。
- 盈亏 = 保证金 × 杠杆 × 价格变化；强平线就是 `1/杠杆`；**亏损上限是保证金，硬币不会变负**。
- 没有任何费用：没有手续费、资金费、点差、追保、保险、单笔/总仓位上限；硬币是唯一约束。
- 15 分钟收盘自动结算，也可随时手动平仓；强平 / 止损按剩余路径逐分钟检查，插针、快进和
  离线补算都躲不过；结算幂等，重启不会重复扣或重复退。
- 到价挂单：目标价 + 方向 / 保证金 / 杠杆，碰到目标价即成交（成交价 = 目标价），只活一根，
  收盘没成交自动撤并退回保证金，也可手动撤；不做部分成交。

## 看盘选项（这一版的最后一块）

- 周期：15 分 / 1 时 / 1 日 / 1 周，各画最近 24 根 + 当前一根；行情用多尺度慢波合成，
  日线/周线能读出趋势（不是噪声）。
- **图表类型**：蜡烛（默认，涨实心 / 跌空心）或**折线**（收盘价折线 + 12% 面积 + 现价圆点）。
- **配色**：彩色或**黑白**。黑白把整窗压成墨色/纸灰，涨跌改用实心/空心 + ▲▼ + 正负号区分，
  不只是换颜色——开会时切一下不显眼。
- 快捷键 `L` 切蜡烛/折线、`M` 切彩色/黑白（输入框与输入法合成中不触发）；偏好存在窗口的
  `localStorage['dsh-zoo-board-prefs']`，重开保留。
- 折线 / 黑白只影响“怎么看”，不改合约、持仓、硬币和周榜。

## 作物：加一种就多一种

盘口作物跟随农场作物目录（只列有底价的），运行时新增或跨机同步来的作物都会自动出现；
作物条单行横滚（左右箭头 / 滚轮 / 键盘 ←→ Home End）。图表按需拉取：打开只带当前作物的
四个周期，切换时再取，单行 IPC 从「15 种作物 308 KiB」降到 **约 17 KiB**，并在 40 种作物下
有护栏测试。

## 真人周榜

- `trading-digest` 每 30 秒 / peer，只发已放行邻居：本周盈亏 + 当前持仓（作物 / 方向 / 杠杆），
  **不含硬币、保证金、入场价、历史**。
- 接收端四道门：已放行、2 分钟内、同 peer 30 秒最多 1 条、字段白名单（positions ≤8）。
- 榜按本周盈亏降序，收益率只展示；LAN 情绪 = 本机 + 邻居当前持仓的多空计数，没仓位写「观望」。
- 旧版本邻居不认新报文：盘口照常、榜上不出现他们，串门 / 礼物 / 农场完全不受影响。

## 兼容性与数据

- 现货交易所、农场、偷菜、雇工、季节、红包都没有改动；`market.json` 与盘口互不写入。
- 新增 `trading.json`（本周盈亏、持仓、挂单、最近 200 条结算）与 `board-window.json`
  （窗口位置）；坏文件按空盘口运行、只告警一次，硬币不动。
- 存档仍是 `version: 1`，纯加法；1.6.x 邻居照常互相串门、送礼、种地。

## 测试

- `npm run check`：**1042 个用例全部通过**（UTC 与 +08 双时区各跑一遍）。
- 盘口窗在 760×700 下用真实 host payload 截图核对：彩色/黑白 × 蜡烛/折线、十字线、
  到价浮层、显示弹层；无页面滚动、无裁切。
- 两台回环 UDP 的 `trading-digest` e2e；假时钟的「开仓 → 止损/强平 → 收盘结算 → 硬币/历史」e2e。
