# dsh-zoo 1.11.0

盘口 v12：行情不再温和单一，消息面会在关键 K 上讲故事，局域网里的真人下单也会推动同一张图。

## 盘口行情 v5

- 15 分钟合约价改成 `clamp(base × exp(W + N + F), base×0.55, base×1.75)`：
  `W` 有波动率聚集、早/夜盘时段、风暴和肥尾跳空；`N` 是每日消息面；`F` 是 LAN 真人资金流。
- 15 分钟 σ 约 2.3%、峰度约 4.2、波动率自相关约 0.12，收益自相关仍接近 0：图更有形状，
  但不会重新打开「读下一根」的套利。
- 每日消息面：每个作物 4–6 条 + 全市场 2–3 条，另有每天 5 个固定日程；
  微讯/快讯/头条/黑天鹅/风暴/传闻-证实六类，全部确定性生成，不联网、不调 AI。
- 关键 K 画小旗/小点，hover 便签同时列出消息与资金流；图头下 16px 快讯条，可点开详情卡。
- 资金流：每人开/平/止损/强平/到价成交都会发一条事件；500 名义 ≈ 0.30%，2 小时半衰期。
  成交价含一半自身冲击，往返净冲击≈0；单笔 ≤0.6%、单设备单根 ≤1.2%、单日 ≤4%、
  每作物水平 ≤1.5%。P2P `board-flow` / `board-flow-sync`，无房主；旧 peer 静默忽略，盘口照常。
  窗口新增「资金流 +0.42% · 鲸 N」、K 线下方资金流点/鲸鱼环、便签流水行和 LAN 情绪净流入。

## 杠杆与界面

- 杠杆档位扩到 **1× / 5× / 20× / 50× / 100×**；50×/100× 的强平线约为 1.9%/0.95% 逆行。
- 选中的杠杆 chip 有档位边框动效：5× 青风双环、20× 琥珀脉冲、50× 紫电双环、
  100× 旋转彩虹环 + 放射速度线 + 心跳发光；切到 100× 会弹漫画气泡
  「老实赚钱，很枯燥吧。」（8 秒自动收，× / Esc 可关）。
- 动效只作用于选中的杠杆 chip；黑白模式转灰阶，`prefers-reduced-motion` 下关闭动画。
- 顺手修正了手续费说明一直显示「开平各 0%」的问题，现在按 payload 显示 0.2%。

## 升级注意

- `PRICE_SALT` 升到 `board-v5`，旧 K 线全部作废；这是有意为之。
- `trading.json` 版本从 1 升到 2；未平仓位会按新行情 re-base 入场价（PnL 从 0 开始），
  开仓时间/顺序不变。未平仓位不会被按一张它们没见过的图结算。
- 老窗口/老邻居兼容：未知字段忽略、未知报文类型静默丢弃；没有 `board-flow` 时只是看不到真人流水。
