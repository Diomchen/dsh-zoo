# dsh-zoo 1.5.0 更新说明

## 四季来了

- 现实中的 1 天相当于 1 个季节，按春 → 夏 → 秋 → 冬循环，在本地时间 0 点换季。
- 新增四种当季作物：豌豆（春）、西瓜（夏）、稻米（秋）、白萝卜（冬）。
- 当季才能买种、种植；当季生长速度加快 10%。
- 换季时，没熟的四季作物会枯萎，已经成熟的可以照常收获；原来的六种作物不受影响。

## 每天一个节日

- 春：播种节；夏：夜市；秋：丰收祭；冬：围炉节。
- 完成当天的小目标后，可以领取硬币和露水奖励。

## 秋天来客：熊獾

- 秋天会出现熊獾，你可以选择“守夜”或“投喂”。
- 成功有奖励，失败会损失少量仓库作物；如果它离开前仍未处理，也会损失 1 个作物。

## 界面

- 农场窗口新增季节栏、四格日历、节日卡和来客卡。
- 枯萎地块可以直接补种。
- 农场窗口改为 520×700，并支持手动置顶。

## 修复

- 测试进程不再向正式局域网广播，避免出现多个同名“幽灵邻居”。
