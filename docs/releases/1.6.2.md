# dsh-zoo v1.6.2

**交易所：局域网指数变成“自适应行情”**

- 指数权重按新鲜邻居数分档：0/1/2/3+ 家 → 0% / 45% / 65% / 75%。
- 再乘作物 beta：番茄、草莓 0.8，胡萝卜、稻米 1.0，玉米 1.1，南瓜 1.3，
  西瓜、葡萄 1.4；有效权重封顶 85%。
- 邻居最近一轮涨跌的中位数形成 ±12% 动量，行情行会显示
  `指数 52% · 2 家 ↑3.0%`；样本过期画灰，没有邻居仍是「本机行情」。
- 只影响卖价；买种子仍然固定价，`/state` 的指数形状不变。
- 交易所每行新增 24 小时成交价折线：取最近 50 笔里该作物的成交并补当前卖价；
  没有成交时画虚线并标「24h · 暂无成交」。

安装：`dsh plugin add dsh-zoo-1.6.2.tgz`（或从 Release 附件下载）。
