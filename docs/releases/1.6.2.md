# dsh-zoo v1.6.2

从 v1.6.0 以来的全部改动。1.6.1 没有单独发版，内容并入本版。

## 交易所：自适应行情 + 24 小时折线

- 指数权重按新鲜邻居数分档：0/1/2/3+ 家 → 0% / 45% / 65% / 75%。
- 再乘作物 beta：番茄、草莓 0.8，胡萝卜、稻米 1.0，玉米 1.1，南瓜 1.3，
  西瓜、葡萄 1.4；有效权重封顶 85%。
- 邻居最近一轮涨跌的中位数形成 ±12% 动量，行情行会显示
  `指数 52% · 2 家 ↑3.0%`；样本过期画灰，没有邻居仍是「本机行情」。
- 只影响卖价；买种子仍然固定价，`/state` 的指数形状不变。
- 每行新增 24 小时成交价折线：取最近 50 笔里该作物的成交并补当前卖价；
  每个成交点悬停时在点的上方弹出「日期 时间 · 单价」，贴着光标、不挤动旁边文字；
  没有成交时画虚线并标「24h · 暂无成交」。

## 露水：按在线时长累计

- 不再要求“10 分钟没做农场动作”：DSH 开着就按时间累计。
- 种、收、浇、施肥、买卖、雇佣、解锁、解冻都不再重置计时。
- 保持每 10 分钟 +1、每天最多新增 48、余额上限 48。
- 本地午夜只重置“今天已挣”的额度，保留未花完的余额。

## 季节来客

- 春·蛙雨、夏·野火改为本地 **09:00–19:00** 之间随机出现，持续 3 小时。
- 秋·熊獾、冬·巨鹿保持本地 15:00 固定出现。
- 窗口按当天稳定哈希计算，重启或多开不会换时间。
- 来客卡上的 0～2 名临时守卫，现在只能从当前空闲的宠物里雇：
  空闲 = 在线、互相放行，且没在自家打工或串门；没有空闲宠物时只能自己守。
  没宠物时选项会禁用并提示「没有足够的空闲宠物」，服务端同样拒绝。

## 铲除

- 生长中或冻住的地块可以「铲除」，免费清空；不退种子、不产作物。
- 冻住的地铲除后省下 2 露水 + 5 硬币解冻费，但作物同样没了。
- 成熟要先收割，枯萎直接重种；窗口两段点击确认，只在主人视图出现。
- 新增 `farm-clear` 动作与 `clear` 日志。

## 兼容性

- `farm.json` 不升版本；旧存档直接沿用。
- 不改 LAN 协议；邻居看不到你的露水。
- 新增回归：`test/market-index.test.js`、`test/market-spark.test.js`；
  赛季/农场用例补到 810 项。

安装：`dsh plugin add dsh-zoo-1.6.2.tgz`（或从 Release 附件下载）。
