# dsh-zoo 1.6.3 更新说明

> 1.6.2 的 tag 是在合并远端「看田窗口」修复之前打的，那个 tag 里没有下面的修复。
> 1.6.3 把两边的改动合到一起，**请用这一版**；已经装了 1.6.2 的，直接覆盖安装即可，
> 存档和协议都没有变化。

## 修复

- **看田窗口不会再自己跳回自己农场。** 之前右键邻居「看看农场」，行情摘要（每 30 秒一轮）、
  邻居来偷、自家作物成熟，随便哪一件都会把只读的看田窗口推回你自己的农场。
  现在它会一直停在对方那一页，只有你点顶部「我的农场」才会回去。
- 看田窗口里地块的倒计时改成走对方家的时间；对方作物熟了会重新拉一份，并提示「熟了，这一趟可以偷」。

## 行情

- 自适应局域网指数：权重按新鲜邻居数 0/1/2/3+ → 0% / 45% / 65% / 75%，
  再乘作物 beta（0.8–1.4），封顶 85%；邻居涨跌形成 ±12% 动量。
- 交易所每行新增 24 小时成交价折线，成交点可悬停，价格显示为贴着点的小气泡。
- 只影响卖价，买种子仍是固定价。

## 农场

- 露水改为「DSH 开着就累计」，农场动作不再重置计时；本地午夜只重置今日额度，保留余额。
- 新增「铲除」：生长中或冻住的地块免费清空，不退种子、不产作物。

## 季节

- 春·蛙雨、夏·野火在 09:00–19:00 随机出现；秋·熊獾、冬·巨鹿固定在 15:00；都持续 3 小时。
- 临时守卫只能从当前空闲的宠物里雇，没有空闲宠物时只能自己守。
- 来客处理完只留一句结论，不再显示下拉框和按钮；节日领过奖也只显示「已领取今天奖励」。
