# dsh-zoo 1.6.3 更新说明

> 1.6.2 的 tag 打早了：那时候还没有合并「看田窗口」修复，所以**请用 1.6.3**。
> 1.6.3 = 1.6.2 的全部内容 + 看田窗口修复，存档、协议、皮肤都没有变化。

## 修复

- **看田窗口不会再自己跳回自己农场。** 之前右键邻居「看看农场」，行情摘要（每 30 秒一轮）、
  邻居来偷、自家作物成熟，随便哪一件都会把只读的看田窗口推回你自己的农场。
  现在它会一直停在对方那一页，只有你点顶部「我的农场」才会回去。
- 看田窗口里的地块倒计时改成走对方家的时间；对方作物熟了会重新拉一份，并提示「熟了，这一趟可以偷」。

## 行情

- 自适应局域网指数：权重按新鲜邻居数 0 / 1 / 2 / 3+ 分别是 0% / 45% / 65% / 75%，
  再乘作物 beta（0.8–1.4），封顶 85%；邻居的涨跌形成 ±12% 动量，看重的是趋势而不是一次报价。
- 交易所每行新增 24 小时成交价折线：绿线涨、红线跌，没有成交时画虚线并写「24h · 暂无成交」。
- 折线上的成交点可以悬停，价格显示成贴着那个点的小气泡，不会再挤动右边的文字。
- 指数只影响**卖价**，买种子仍然是固定价，不会因为邻居把种子买贵。

## 农场

- 露水改成「DSH 开着就累计」：种、收、浇、施肥、买卖、雇佣都不再重置 10 分钟计时，
  本地午夜只重置「今天还能挣多少」，已经攒下的余额不会被清掉。
- 新增「铲除」：生长中或冻住的地块可以免费清空，不退种子、也不产作物；
  成熟的地要先收割，枯萎的地直接重种。第一次点会变成「确认铲除？」，再点一次才真的铲。

## 季节

- 四季来客：春·蛙雨、夏·野火在 09:00–19:00 之间随机出现；秋·熊獾、冬·巨鹿固定在 15:00；
  每位来客只停留 3 小时，错过就按「没来得及应对」结算。
- 临时守卫只能从当前空闲的宠物里雇：没有空闲宠物就只能自己守，雇 1 位 80%、雇 2 位 100%。
- 来客处理完的卡片只留一句结论，不再显示下拉框和按钮；节日领过奖也只剩「已领取今天奖励」。

## 怎么更新

- DSH 里已经装过 dsh-zoo：用新包覆盖安装，然后**重启 DSH**（只重开农场窗口不够，宿主那半边也要重载）。
- 新装：`node scripts/install.mjs --profile desktop`，或在 DSH 插件页安装 `dsh-zoo-1.6.3.tgz`。
- 存档不需要迁移：`farm.json`、`season.json`、`peers.json` 都按原格式读取，旧数据直接能用。
