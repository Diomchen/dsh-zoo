# 1.12.0：暂停和退出都是自己的事

房主掉线，全场的仓位不会消失；房主不高兴，也没人能按一个按钮把你按住。

## 为什么要改

票 98 做的「三档灰度」里，`off` 是房主手里的全局闸门：按一下，所有人的新仓、挂单、
结算报文一起停。`futures-rollback` 也是全场动作——房主强平所有人，再把每个人的托管
余额退进**自己**的农场，给对方记一条 `pending` 欠账。

局域网里没有监管者，这些权力只能靠代码约束。1.10.0 已经把「玩不玩真钱」下放到账户
自己；这一版把最后两件「别人的按钮能影响我」的事拆掉：

- 房主关市 ≠ 全场停摆；
- 房主回滚 ≠ 替全场退款。

## 现在怎么用

窗口顶栏三颗按钮，各管各的：

| 按钮 | 对应动作 | 只影响 |
| --- | --- | --- |
| 切到真钱／切到纸面 | `futures-account-mode` | 自己这本账的档位 |
| 暂停交易／继续交易 | `futures-pause` | 自己的新仓与新挂单 |
| 退出 | `futures-rollback` | 自己的仓位、托管余额 |

暂停时：新仓、挂单被拒（`paused`），已开的仓、余额、挂单都留着；平仓、撤单、转现货、
提现照常——这些都是减风险的动作，不该被自己的暂停挡住。

退出时：按当前公允价强平自己的仓位，自己的余额退回自己的农场（撞 1,000,000 上限的
部分留在自己的 `pending`），这本账标 `disabled`，数据保留不删。

```
POST /dsh-zoo/action {"action":"futures-pause","paused":true}
POST /dsh-zoo/action {"action":"futures-rollback"}
```

老脚本里 `{"action":"futures-mode","mode":"off"}` 仍然能跑，但现在只等于「暂停自己」。

## 房主还剩什么

房主只剩三件事：排序（谁是房主）、记账（撮合、余额、强平）、广播（`futures-settle`）。
他停不了别人的市，也退不了别人的钱；他能做到的最坏情况是**不广播**——市场停在最后
一拍，各自的仓位和余额还在房主那台的账本里。

peer 调 `futures-rollback` 会回 `not-owner`，提示「先把仓位平掉、余额提回农场」：
peer 的账在房主那台，本地没有可退的钱。

## 兼容性

- 新报文 `futures-pause { paused }`（peer → 房主申报）；settle 增加可选字段 `paused`，
  缺省 `false`，只在该账户暂停时为 `true`。
- 旧 `futures.json` 没有 `paused` 字段，读盘时补 `false`；旧 peer 不发暂停报文，
  房主按 `false` 处理。
- `mode` 字段保留但不再作为闸门；`futures-mode` 动作变成 `futures-pause` 的别名。
- 入站 `futures-*` 不再因为「房主关市」被整批丢弃，只按账户自己的 `disabled` 决定。

## 顺手修的

- 窗口顶栏原来在 `off` 时会把整个 modebar 画成「期货未开放」，现在只有账户自己退出
  才这样；暂停时按钮变成「继续交易」，倒计时和报价照常。
- `futures-view.js` 的 `statusOf()` 不再用市场模式兜底，暂停不再被画成「休市」。
