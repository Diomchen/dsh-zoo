# dsh-zoo 1.14.0

这一版加了一个新玩法：**出远门**。地买满之后硬币没处花，这是它的出口——盘缠交出去就不退，
带回来的只有特产和图鉴上的格子。另外把出远门窗口从「点开没反应」修到能用，顺手补上
两处新加的桌面动作字段。

设计与取舍写在 [ADR-0039](../adr/0039-expedition-burns-coins.md)，
玩法细节（路线表、掉落表、状态机、动作契约）在 [docs/play-expedition.md](../play-expedition.md)。

## 一、出远门：把硬币烧在路上的玩法

一趟 2–5 分钟，随时可停，关了窗口也继续走：

1. 选一条路线，交**盘缠**（后山 500 / 废矿 3,000 / 老铁路 15,000 / 雾岭 60,000）。
2. 每 20 秒走一段：先掉一笔硬币，再告诉你现在的**危险度**。
3. 你选「继续走一段」或者「见好就收」——折返就把已经拿到的都带回家；
   继续走，危险度往上叠，翻车就丢一半特产、提前回家。
4. 回到家：特产进**陈列架**、进**图鉴**，写一篇**旅行日志**；邻居串门和公开视图
   看得到你集齐了几件、架子前 8 格摆了什么。

净消耗是盘缠的 80%–90%：走满一趟的硬币回报只有盘缠的 9%–21%，特产**不能卖**，
只能陈列、收进图鉴（v2 才考虑塞红包送人）。硬币 37 万大约等于 826 趟后山，或者
7.7 趟雾岭。

- 四条路线按图鉴件数与趟数解锁：后山无条件 → 废矿 3 趟后山 → 老铁路图鉴 16 件 →
  雾岭图鉴 24 件且走过老铁路。
- 升级只有两件：**提灯** 10,000（把危险度从「低/中/高」变成精确百分比）、
  **陈列架格** 5,000/格（默认 8 格，最多 32 格）。
- 图鉴 32 件、每条路线 8 件，稀有度分四档，同一趟不会掉重复件；集齐一条路线的 8 件后
  只掉没见过的。

## 二、窗口之前为什么点不动

三处断链，都是「四跳白名单少抄一处」这一类：

- **桌面那一跳**（`handleDesktopAction`）只抄了农场与盘口的字段，`routeId`、
  陈列架的 `slot`/`itemId`/`moveFrom`/`moveTo`、`tab`、`expectedUnlocked` 全被丢在路上。
  于是窗口点「出发」永远回「没有这条路线」，而 HTTP 与脚本却是好的——端到端测试
  走的是 HTTP，一直全绿。现在补齐，并加了一条「窗口能发的字段，服务端这一跳也得原样带上」
  的对账测试。
- **preload 白名单**漏了 `expedition-lantern`，买提灯只弹「这个动作发不出去」。
  现在窗口侧与 `shared.js` 的动作表加了双向对账测试，少一处就红。
- **窗口脚本本身**第一行 `'use strict'` 后面直接跟 `(function () {`，缺分号，
  整份脚本被解析成「调用字符串」，一加载就抛 `TypeError`，窗口只剩静态 HTML。
  已修，并加了一条真的把脚本跑起来的启动回归。

## 三、这一轮修掉的逻辑问题

- **重启会掉重复特产**：读档续走那段没把「图鉴已集齐」传下去，同一份存档
  「重启」与「不重启」掉的东西不一样。
- **陈列架能摆没捡到过的特产**：空图鉴也能把 8 格摆满，邻居看到的是假的。
  现在只认图鉴里有记录的，并把失败拆成「格子没开 / 格子被占 / 空格 / 同一格 /
  还没捡到过」，不再一律提示「这个格子还没开」。
- **决策窗过了还能点「继续」**：tick 抖动时晚点的那一下能白走一段。现在过期就按
  「没等到你，自己回来了」结算，和超时同口径。
- **农场页「日志·看全文」**落在旅行首页，窗开着时点它反而把窗关掉。现在带
  `tab:'log'` 直接落在日志页；带落点的入口在窗已开时改为聚焦切页，不再关窗。
- **串门/打工时出发键仍可点**：点了必然被拒，还和上方的「先等它回来」自相矛盾。
  现在按钮直接是灰的。
- **出远门借用盘口的报错**「盘口窗指令发不出去（盘口数据可能太大）」，已改成自己的文案；
  `expedition-refresh` 在窗没开时不再报失败，也会先走一拍 tick。
- **「出门」与「打工」能同时成立**：扣盘缠要写农场档、中间有 await，那几十毫秒里
  入站打工能挤进来。现在先把 run 立住再扣钱，扣失败再回滚。

## 四、窗口的可用性

- 页签补上 `role="tablist"/"tab"`、`aria-selected`、`aria-controls`；提示条
  `role="status" aria-live="polite"`；关闭键有 `aria-label`——读屏能读出「选中了哪个页签」
  和每一次失败提示。
- 重绘是「清空再建」，键盘焦点以前每次推送都掉回 `body`。现在按
  `data-focus-key` 把焦点还回原来那张路线卡或那个陈列格。
- 视图里 `run` 缺失时不再整窗抛 `TypeError`，停在半画状态。

## 五、期货申报的补发（票 121）

申报丢一包就永远丢了：peer 只发一次、没有重传，房主的节流还挂在被冻住的游戏时钟上。
现在 `futures-settle` 带回 `ackAt`，房主说「你这个 peer 我处理到哪一笔了」，peer 收到回执
才清掉重发队列；房主侧按 `(deviceId, kind, at)` 去重，补发包只换回一份回执、不二次记账。
诊断过程与实测数字在票 121 的结果段里。
