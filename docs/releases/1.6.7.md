# dsh-zoo 1.6.7

**红包页终于能选作物和种子了；顺手修掉一个会让插件直接加载失败的 BOM。**

## 修了什么

### 1. 红包底数在宿主桥接层被削掉

1.6.6 修的是 helper 主进程拿到 `packet` 之后没往下传；这次补的是它前面那一跳：

- 宿主 `src/desktop.js` 的 `bringWindow()` 按白名单重建命令，只写了 `type/open/items`，
  宿主算好的 `packet`（今日剩余、硬币、可放作物/种子及各自数量）在这里就被丢了。
- 窗口因此一直显示「宿主还没把红包底数据过来」，作物、种子两栏是空的。

现在 `packet` 原样随 `bring-window` 下发；旧宿主或无红包数据时该字段缺省，窗口行为不变。

### 2. `package.json` 开头多了 BOM

打 1.6.7 的包时用 PowerShell 5.1 的 `Set-Content -Encoding utf8` 改了版本号，它会写 UTF-8 BOM。
插件加载器用严格 `JSON.parse`，于是整个 bundle 报：

```
Unexpected token '﻿', "﻿{ "name"... is not valid JSON
```

已改成无 BOM 的 UTF-8，并加了一条守卫测试 `test/package-json.test.js`：断言
`package.json` 不以 `EF BB BF` 开头、能被严格解析、末尾只有一个换行。
全仓库扫过一遍，没有别的文件带 BOM。

## 兼容性

- 协议没有新增包类型，`farm.json` / `season.json` / `market.json` / `gifts` 目录格式都没变。
- 改动只在桌面桥接白名单、`package.json` 编码与测试，农场、季节、行情逻辑不动。
