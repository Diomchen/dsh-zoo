# dsh-zoo 1.6.7

**红包页终于能选作物和种子了。**

## 修了什么

1.6.6 修的是 helper 主进程拿 `packet` 之后没往下传；这次补的是它前面那一跳：

- 宿主 `src/desktop.js` 的 `bringWindow()` 按白名单重建命令，只写了 `type/open/items`，
  宿主算好的 `packet`（今日剩余、硬币、可放作物/种子及各自数量）在这里就被丢了。
- 窗口因此一直显示「宿主还没把红包底数据过来」，作物、种子两栏是空的。

现在 `packet` 原样随 `bring-window` 下发；旧宿主/无红包数据时该字段缺省，窗口行为不变。

## 兼容性

- 协议没有新增包类型，`farm.json` / `season.json` / `market.json` / `gifts` 目录格式都没变。
- 只改桌面桥接层的一行白名单与一条回归测试，农场、季节、行情逻辑不动。

## 测试

`npm run check`：841 个用例，840 通过、1 跳过（Windows 上 chmod 用例）。
新增 `manager：bringWindow 把背包快照写进管道，路径不在命令里` 对 `packet` 的断言。
