# dsh-zoo 1.6.5

一句话：带派能寄红包了——硬币、作物、种子装一只，点「拆开」才进对方农场。

## 新增：带派红包

- 带派小窗顶部多了两个页签：「字条」和「红包」。红包页可以填硬币、从仓库挑作物、
  从种子袋挑种子，再写一句 ≤60 字的祝福语，右下角实时显示这一只装了什么。
- 额度：硬币 ≤200，每种作物/种子 ≤20，作物和种子各 ≤5 种；每天最多寄 **3 只**。
  helper 与宿主各夹一次，页面上的数字永远不超过宿主给的上限。
- **寄出即扣**：点「放进背包」时先从自己农场扣掉，撤回背包里的红包会原样退回。
- **拆开才到账**：对方访客卡上有一个「拆开」按钮，点完内容直接进他的农场
  （硬币、作物、种子），不占背包格；不点就一直放着。
- **24 小时退回**：没拆的红包一天后自动退回发送方；对方离线就留在宿主重试表里，
  下次上线补退。红包不会凭空消失，最坏显示「待退回」。
- 拆开/退回都写进 `gifts/<目录>/meta.json`，重放请求不会给第二次。

## 细节

- 协议新增 `packet-return` / `packet-returned` 两个包类型，都不进访客身份重建；
  旧版本收到会当未知类型忽略，串门照常。
- 红包卡不再显示「打开 / 在文件夹里显示 / 复制」，只留内容摘要、祝福语和状态。
- 农场日志、季节、交易所都不受红包影响；拆到的硬币/作物/种子和正常收入同一条账。

## 兼容

- 纯增字段：`gift.kind` 多一个 `packet`，`season.json` / `farm.json` / `market.json`
  格式不变，旧存档直接可读。
- 1.6.4 及更早版本收到红包会显示「没送到」并退回发送方背包——不会丢东西，
  但要看内容需要双方都升到 1.6.5。
