# dsh-zoo 1.8.0

期货上线：一间由**房主当清算所**的小市场，玩家之间挂单撮合、周五到期交割。它跟盘口不是一回事——
盘口是「跟机器对赌 15 分钟涨跌、零费用、几乎不会爆仓」；期货是「跟人做对手盘、一周一张合约、
托管账户里的钱真的会亏完」。

## 期货窗

- 桌面右键「期货」打开；约 **760×700**，可拖标题栏移动，位置记在 `userData/futures-window.json`。
- 窗里自上而下：余额条（可用 / 占用 / 权益 / 本周盈亏 / 保险基金 / 欠账）、三档灰度条、
  报价表（每作物一张合约：买一 / 卖一 / 价差 / 偏离现货指数 / 点差）、下单区、限价挂单、
  底部两行（持仓通栏 + 我的挂单 / 最近成交）。
- 持仓行「平」按公允价平仓，「转」按公允价把这张合约转成现货作物；挂单行「撤」撤销并退回冻结保证金。

## 合约与撮合

- 一周一张合约：周一 00:00 上市、**周五 20:00 到期**（`tomato-2026W47` 这种代号）；周末没有合约。
- 一张 = 100 个作物；杠杆 1× / 3× / 10× / 20×；保证金 1–1,000,000 的任意整数。
- 公允价由 15 秒一步的均值回归过程生成（`OU_SIGMA = 0.4%`、半衰期 30 分钟），做市商在公允价
  两侧挂 ±0.2% 的买一 / 卖一；**手续费 0.1%**（taker，两边都收），其中 10% 进保险基金、90% 销毁。
- 玩家挂单按**价格优先**撮合，成交价取 maker 的价；每 15 秒撮合一次，有新单立刻再撮。
- 单笔名义 ≤ 20,000 币；每人同时最多 8 条挂单、最多 8 个仓位。

## 结算、交割与费用

- 每 15 秒**盯市**：浮盈亏入余额、持仓的 `entry` 改成新价，仓位与张数不动。
- 每根 15 分钟**净额结算**一次，根末向邻居广播 `futures-settle`；重启幂等，不会重复扣或重复退。
- 到期交割：取 19:15 / 19:30 / 19:45 / 20:00 四根公允价收盘的**算术平均**作交割价，
  现金结算并收 0.1% 交割费；也可提前手动「转现货」，按公允价换成作物，收同一档费用。

## 强平与保险基金

- 逐 15 秒重算：`保证金 + 浮盈亏 ≤ 0` 即强平，按触发那一刻的公允价成交（1× 等价于没有强平线）。
- 强平后如果亏空超过保证金，先花**保险基金**，不够的部分记成 `shortfall` 欠账——
  账户余额永不为负，基金余额也永不为负。

## 三档灰度与敞口限额

| 档位 | 谁能下单 | 日额（名义） | 用途 |
| --- | --- | --- | --- |
| `off` | 谁都不能 | — | 关掉期货，收发都停 |
| `shadow`（默认） | 谁都不能（只记账） | 0 | 对账用：只跑账本，不碰农场硬币 |
| `live` | 所有已放行邻居 | 5,000 / 账户 / 自然日 | 真钱 |

- 房主在窗口灰度条里切档（切 `live` 要确认），HTTP 也可：
  `{"action":"futures-mode","mode":"live"}`；出问题用 `{"action":"futures-rollback"}`
  一键回滚（撤挂单 → 按当前公允价强平 → 逐账户退款 → 打 `disabled`，数据不删）。
- 影子档日额是 0：新开仓 / 挂单在余额校验之前就被 `daily-cap` 拦住，免得余额变成侧信道。
- 进来的包先判档位再限速：**同源 20 包 / 10 秒**，单包 ≤ 4 KiB；超了直接丢，不回包。

## 修了什么

- `desktop/futures.js` 顶上写 `'use strict'` 换行接 IIFE，被解析成 `'use strict'(...)` 调用，
  一加载就 `TypeError`，整扇窗停在「—」占位符——**期货窗从票 92 起其实一直没画出来过**。
  已把指令挪进 IIFE，并补 `test/futures-script-load.test.js`（假 DOM 真跑一遍 + 推一份 view
  断言画到了 DOM）与 `scripts/check-desktop.mjs`（`desktop/` 下每个脚本都过 `node --check`，
  以前是手写清单，加窗口就漏）。

## 兼容性与数据

- 现货、盘口、农场、雇工、季节、红包都没动；`futures.json` 与 `market.json`、`trading.json` 互不写入。
- 新增 `futures.json`（托管账户、仓位、挂单、成交流水、灰度档位与日额）与 `futures-window.json`；
  坏文件按空账本运行、只告警一次，农场硬币不动。
- 协议只加 `futures-hello` / `futures-announce` / `futures-settle` / `futures-sync` / `futures-trade`
  五个包，旧邻居不认就直接忽略——串门、礼物、盘口、农场不受影响。
- **默认是 `shadow`**：装完不会有人被扣钱，房主切到 `live` 才开始真钱交易。
