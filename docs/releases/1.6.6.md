# dsh-zoo 1.6.6

一句话：修 1.6.5 的红包页——现在真能从仓库和种子袋里挑东西了。

## 修复：红包页看不到作物和种子

1.6.5 打开「带派 → 红包」时，作物、种子两行是空的，底下只有一句
「宿主还没把红包底数据过来」，硬币能填但挑不了东西。

根因在 helper 的主进程：宿主已经把红包底数（上限、今天还能寄几只、仓库作物、
种子袋种子）放进 `bring-window` 一起发下来了，`shared.normalizeBringWindow`
也认这个字段，但 `desktop/main.js` 组装 `giftState` 时只抄了
`items / count / maxItems / maxTextLength / maxFileBytes`，`packet` 在这一跳被削掉，
窗口拿到的永远是 `null`。

修法：`giftState` 带上 `command.packet`（宿主没发就不带，旧宿主仍然退回「字条」页）。
新增回归用例在 `test/packet-ui.test.js`：`bring-window` 的红包底数要穿过白名单和主进程，
顺带验旧宿主不发 `packet` 时不会凭空造数据。

## 没改什么

- 红包协议、额度、拆开/退回逻辑都不动；`farm.json` / `season.json` / `market.json` 不升版本。
- 1.6.5 存档与背包里的红包照常可用，不需要迁移。
