# dsh-zoo 1.6.8

这一版只修真问题：带派窗口里，红包面板把底栏挤出可视区。

## 带派窗口：红包能填，也能取消

1.6.5 加了红包以后，窗口仍是给「字条」定的 380×480。红包要放硬币、最多 5 种作物、5 种种子、祝福语和摘要，整张卡片比字条高出一大截，`取消` 和 `放进背包` 被顶到卡片外面：既提不了交，也关不掉窗口。

现在：

- 窗口放宽到 **400×620**，红包面板一次能看到更多行；
- 卡片内容可以纵向滚动，作物/种子行再多也不会把下面挤没；
- 底栏 `取消 / 放进背包` 用 sticky 钉在卡片底部，滚动时始终可点。

## 兼容性

- 存档、协议、红包规则都没变，1.6.7 及更早的版本照常互相收发。
- 只改了窗口尺寸和两处 CSS，不需要迁移。

## 测试

- `npm run check`：843 个测试，842 通过、1 跳过（Windows 上 `chmod` 用例跳过）。
- 新增守卫：`红包面板比字条高：窗口要够高，底栏要钉住`（`test/packet-ui.test.js`），防止以后再把窗口改小。
- 实机核对：helper 窗口实测 400×620，截图里 `取消`、`放进背包 →` 完整可见。
